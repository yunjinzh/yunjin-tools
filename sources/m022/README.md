# 小小英语冒险家 3D · 第三版

面向小学生的本地可运行 Three.js 学习游戏。词表复用此前用户提供的 Word list 第 128–135 页，399 个词条、391 种不同英文拼写，按导入与 Unit 1–9 原顺序组织为 69 组。

## 第三版：用单词唤醒小岛（2026-10-10）

- **星光远航**：每组六词按听音收集、字母拼装、独立拼写三个阶段推进，共十八题；末组不足六词时使用实际词数。已完成题目自动存档，中断后从下一道未完成题继续，保留本题提示和错误状态。
- **十种主题机关**：摩天轮、博物馆展柜、开花树、救援车、环岛列车、秘密信封、彩虹桥、音乐舞台、火箭与营地星灯。拼写关卡呈现对应机关，答对触发光能轨迹、伙伴回应和机关动作。
- **可以成长的小岛**：任务中用能量晶石显示本次进度；回到岛屿后，机关依据本单元曾独立拼对的词条比例保留成长。
- **昼夜与生态**：晴昼、黄昏、星夜联动天空与海面着色器、雾色、太阳位置和光照；新增飞鸟、星点、萤火虫、月亮，地图增加沿曲线路径航行的飞艇。
- **探索护照**：每座岛有贝壳、星种、漂流信件三个发现，共三十枚印章；三维物件与护照按钮均可访问。发现时打开该单元固定词条的听读与练习卡，每处只奖励一次星晶。
- **冒险明信片**：隐藏学习界面、暂停当前学习或消消乐、拖动构图、缓慢环绕、切换天空，导出真实三维画面的 PNG；退出后恢复进入前的暂停状态。
- 保留旧版的底部悬浮操作区、自动切题、原词表和全部游戏。新字段在读取旧存档时补充，仍使用原有存储键。

## 延续的交互与场景

- 学习操作、选词、拼写和反馈统一在三维场景底部悬浮，取消左右分栏。桌面选词四列，小屏两列；主镜头根据可见面板留出空间。
- 答对后展示反馈并自动进入下一词，停留 1.5–3.4 秒，按词长调整。支持暂停、立即继续；打开弹窗和切入后台暂停倒计时；切换任务清除旧题状态。
- 字母拼齐自动检查，支持鼠标点选、拖入槽位和键盘输入。三维字母飞入上方拼写槽，取回与修改同步到场景。
- PerspectiveCamera、OrbitControls 拖动旋转与双指缩放、镜头复位、平滑镜头转场及底部遮挡补偿。
- 程序化不规则岛岸、分层地形、动态海面着色器、云层、环境光照、柔和阴影、ACES 色调映射和柔和泛光；批量绘制草丛，提供精致／流畅两档画质。
- 六种功能入口采用不同的三维造型；悬停高亮、提示、选中反馈、连续答对提示、三维粒子和奖励牌。
- 消消乐增加可点击的三维列、半透明落点预览和落块平滑移动，面板与按钮集中在底部。
- 延用第一版存储键与格式，保留教材顺序、奖励规则和旧存档。

## 可玩内容

1. 三维单元地图：10 座可点击的单元岛屿；主岛可点击地面移动伙伴、点击建筑进入任务，滚轮缩放。
2. 听音寻宝：设备英语朗读、三维单词物件或宝石选择、中文线索和错误后的再次尝试。已制作模型的名词用小型物件表达，其他词使用带英文铭牌的宝石。
3. 字母工坊：三维字母点选、页面字母点击或拖放、取回修改、完整排列检查。
4. 记忆补全：展示部分字母，要求完整输入；单独记录提示拼写。
5. 独立拼写：根据词义和发音完整输入，保留短语空格、连字符；提示和本题订正均不记为独立正确。
6. 三维下落消消乐：重复单词、三张正交连通消除、重力连锁、四列八行容器、触顶六秒补救、满仓结束、暂停、三档速度。
7. 故事任务：每单元一条固定小故事，按辨认、拼装、独立拼写完成三个阶段；完成后点亮单元地标。末组只有一两个词时重复用于不同阶段。
8. 星光试炼：每组每个词都接受辨义、听词辨义、完整拼写三个环节，六词组共十八题。
9. 宠物伙伴与家园：改名、三种颜色、击掌庆祝、等级、六件可购买且实际出现在三维场景中的家园装饰。
10. 复习邮局、单词图鉴和观察台：到期复习、搜索筛选、逐词听读和练习、单元进度、错词、徽章、学习设置、CSV 导出、JSON 存档备份与恢复。

## 学习与奖励

辨认、字母拼装、记忆补全、独立拼写、错误和隔日复测分别记录。只有无提示且本题未答错的完整输入记为独立拼写。相隔至少二十四小时的独立正确输入计为隔日复测。复习间隔是产品设定，尚无儿童试玩成效数据。

任务首次完成奖励五颗星晶，首次三星额外奖励两颗；重复任务保留最佳成绩。图鉴的单词练习和到期复习是针对练习，不领取任务首通奖励。消消乐根据同组最高消除数领取增加的档位奖励，最高十二颗。家园购买验证余额且仅能购买一次。

## 运行与数据

直接用现代浏览器打开 `dist/index.html`，无需安装依赖或连接 CDN。Three.js、样式、逻辑、词表全部内嵌在单个 HTML 中。浏览器需支持 WebGL 2 才能显示三维场景；未开启三维时仍能通过文字控件练习。

英语朗读使用浏览器设备语音，是否可以完全离线朗读取决于设备安装的语音。默认无登录、无服务器上传。进度只存于当前浏览器，换设备前导出 JSON 存档。存储键为 `little-english-adventure-3d-v1`，独立于先前消消乐和探险岛。恢复前自动下载旧存档备份。

## 开发和检查

- `node build.mjs`：生成自包含 HTML。
- `node verify.mjs`：检查教材覆盖、判题、学习状态、复习时间、奖励去重、存档验证、消消乐，以及实际 Three.js 场景结构和 DOM 操作流程。
- 全部 399 个词条的独立拼写流程在 DOM 测试中逐个运行；全部十个单元的三维场景都检查了场景结构和有限坐标。
- 第三版共通过 53 项自动检查，包括全部 399 词条的独立拼写与自动切题、全部词条的字母拼装、暂停／后台／弹窗／切换任务、镜头投影边界和消消乐落点；并覆盖全部远航排题、续玩提示标记、印章奖励去重、十种机关动画、昼夜材质、拍照暂停恢复与旧存档迁移。
- 当前验证不包含 GPU 实际渲染、真实设备布局、音频播放或儿童学习成效测试。浏览器预览能力在本次环境中不可用。
