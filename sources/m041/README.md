# 城迹 · 中国地标三维图鉴

用可旋转、缩放的三维建筑形态模型，探索中国七座城市的古今地标。

内置模型由 Three.js 几何体构建，体现建筑的主要轮廓和结构，细节经过简化。建筑介绍、资料出处和照片署名记录在 app/data/landmarks.json，并在介绍浮层中展示。远程实景照片暂时不可用时，缩略图会切换为对应的三维模型图。

## 操作

- 在左侧切换城市，点击建筑缩略图。
- 拖动旋转、滚轮缩放、右键平移；移动设备支持单指旋转和双指缩放、平移。
- 使用画面下方的按钮缩放、旋转或重置视角。
- 切换白天与夜晚，查看自然光和建筑夜景照明。
- 介绍面板可以收起，也可以在观察模型时保持展开。

## 自定义地标

“添加我的地标”支持 GLB 单文件，或 glTF 2.0 与配套的二进制和纹理文件。可以一次选择多个文件或完整文件夹。多个模型文件可选择主模型，资源合计最多 120 MB。内置 Draco、Meshopt 和 KTX2 解码支持。

导入后先预览三维模型，再填写城市、名称、建筑类型、时间、位置和介绍。模型自动居中并适配尺寸，预览图作为列表缩略图。保存后的地标支持编辑模型和介绍。

自定义内容保存在当前网站、当前浏览器的 IndexedDB 中。模型不上传至服务器，不会在设备间同步；清除浏览器网站数据会删除它们。

## 项目结构

- app/city-atlas.tsx：城市导航、主界面和地标介绍。
- app/landmark-engine.ts：三维渲染、视角、照明、glTF 加载。
- app/landmark-models.ts：14 处建筑的程序化形态模型。
- app/upload-landmark.tsx：模型上传、预览、资料编辑。
- app/model-files.ts：资源解析、完整性检查、本地保存。

基于 Vinext / React / Three.js / shadcn/ui 构建。

## 开发

使用 npm install 安装依赖，npm run dev 启动开发环境，npm run build 构建发布文件。类型检查：npx tsc --noEmit。
