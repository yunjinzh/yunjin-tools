# EV-SIM 新能源汽修虚拟实训 MVP

交付版本：2026-10-08 / 模型更新 v1.1，教学规则 SIM-1.0。

## 已实现

- Three.js 加载用户提供的 2018 Tesla Model 3 GLB、可旋转缩放、部件拾取、透视、分层、视角切换、举升和电池移动；WebGL PBR 环境光与阴影，WebGL 不可用时切换 基于同一 Three.js 场景与逐像素深度缓冲的 Canvas 兼容显示。
- 16 项电池拆装任务、26 次操作；学习/练习/考核；防护确认、工具和对象校验、模拟仪表挡位、6 颗教学紧固件拆卸/紧固、托举联锁、关键违规终止。
- 5 类确定性教学故障案例：互锁、绝缘、温度采样、接触器反馈和冷却；测量证据、原因选择、处理、复测和诊断报告。
- D1 保存成绩与操作证据；服务端依据事件重算拆装分数；成绩 CSV、报告 JSON、浏览器打印/PDF；状态时间线回放。
- 教师工作台：成绩、错误统计、复核意见。个人体验工作区中提供教师功能，无独立教师账号。

## 使用

1. 在右上角输入体验学员姓名。
2. 学习模式点击“定位当前教学部件”，完成防护检查，执行当前操作。
3. 按当前任务切换工具与部件，逐颗完成拆卸和紧固；教学工单可随时查阅。
4. 完成后查看报告并点击“保存记录”。阶段报告也可保存，继续同次训练后可更新该记录。
5. 诊断模块先采集证据、选择原因，再处理和复测，保存诊断报告。
6. 教师工作台查看报告、记录复核意见。虚拟合格不自动颁发真实操作资格。

## 技术

React 19 / TypeScript / Vinext / Three.js / Cloudflare Workers / D1。车身使用用户提供的 GLB；电池与工位设备为程序化通用教学结构。依赖及资源在构建中打包，不依赖第三方 CDN。

- `app/page.tsx`：实训、诊断、报告、教师视图。
- `components/ev/Scene.tsx`：场景构建、动画和拾取。
- `lib/training.ts`：共享教学步骤、状态转移、评分与案例。
- `app/api/attempts/route.ts`：成绩持久化与服务端重算。
- `app/api/reviews/route.ts`：复核记录。
- `db/schema.ts` / `drizzle`：表结构与迁移。

安装依赖使用项目锁文件。`pnpm build` 构建；`pnpm dev` 开发。D1 本地迁移按 Sites/Vinext 项目约定，在构建生成 Wrangler 配置后执行：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_chubby_roughhouse.sql
```

## 真实性与边界

车身使用附件《Tesla 2018 Model 3》，实际车型标签已同步；电池和高压操作部件为通用教学结构，不能视为 Model 3 原厂内部构造。SIM-1.0 的 24 N·m、6 颗紧固件、13.2 V 和 0.0 V 均是教学设定，不能用于实车维修。未核定具体车型配置、原厂拆装规程及真实维修参数。

部分作业被合并表达，例如冷却回收与封护；没有完整电化学或热流仿真，也没有力反馈、真实 OBD/CAN、学校多账号/角色权限或正式防作弊监考。本 MVP 的操作日志可用于教学演示和产品试用，不能作为职业资格证据。

## v1.1 附件车模更新

- `public/models/tesla_2018_model_3.glb`：用户附件原文件，约 22 MB / 684,315 个三角面，内嵌 22 张纹理。正常 WebGL 模式保留完整几何与纹理。
- `public/models/tesla_2018_model_3.compat.glb`：从同一车模网格减面生成，约 0.4 MB / 17,744 个三角面；WebGL 不可用时使用，省略内饰并将纹理均色化。它不是精细材质预览。
- `components/ev/VehicleModel.ts`：本地 GLB 加载、进度与重试、尺度/朝向适配、材质调整、透视、资源释放。车身和车轮分组支持举升与分层。
- `scripts/prepare-model-compat.py`：可复现轻量模型的离线脚本；只在重新制作资产时需要 Python 依赖，不影响应用构建。
- 依据附件内嵌元信息：模型《Tesla 2018 Model 3》，作者 [Ameer Studio](https://sketchfab.com/uchiha.321abc)，[原始来源](https://sketchfab.com/3d-models/tesla-2018-model-3-5ef9b845aaf44203b6d04e2c677e444f)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。修改包括展示比例、朝向、车漆/玻璃材质，以及轻量版减面与纹理均色化。上述署名同时显示于应用“关于”及教学工单。

### v1.1 验证

- 附件原文件 SHA-256 一致，22 张内嵌贴图均可解码；Three.js GLTFLoader 能解析完整与轻量两个版本。
- 浏览器验证模型加载、结构透视、分层、视角切换，以及已有训练记录的举升/电池拆出回放；修正举升臂穿模、分层穿地及移出电池的镜头对位。
