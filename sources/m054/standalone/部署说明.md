# 云金个人作品网站——本地与云服务器部署说明

这个版本已经生成完整静态网站，不依赖数据库，也不需要配置大模型接口。网页字体为随包提供的思源宋体可变字体，打开网站时不会向外部字体服务发送请求。

## 一、Windows 本地运行

1. 安装 Node.js 18 或更高版本。
2. 解压整个压缩包，路径中可以包含中文。
3. 双击 `启动网站.cmd`。
4. 系统会自动打开 `http://127.0.0.1:4173`。
5. 不要直接双击 `site/index.html`，通过启动文件访问才能保证作品详情、PDF 与视频预览正常工作。

关闭命令窗口或在窗口中按 `Ctrl+C` 即可停止网站。

## 二、更新个人作品

### 最简单的方式

把图片、PDF、PPT、Word、Excel、HTML、视频或三维模型直接放入 `作品文件` 文件夹，然后双击 `重新生成网站.cmd`。刷新浏览器后，新文件会自动形成作品卡片和详情页。

### 一个作品包含多份文件

在 `作品文件` 中为该作品新建一个文件夹，把封面图片、文档、视频或模型放入同一文件夹。系统默认使用第一张图片作为封面，其余文件列入详情页附件。

可在作品文件夹中增加 `project.json`，用于精确设置标题、简介、标签和详情内容。现有六个示例项目都提供了可直接复制修改的 `project.json`。

常用字段如下：

```json
{
  "title": "作品名称",
  "category": "数字孪生 / 校园治理",
  "year": "2026",
  "summary": "卡片上的简短说明",
  "description": "详情页的项目总述",
  "role": "产品架构 / 交互设计",
  "tags": ["数字孪生", "GIS"],
  "tone": "coral",
  "size": "small",
  "order": 1,
  "cover": "cover.jpg",
  "challenge": "项目背景",
  "approach": "设计方法",
  "outcome": "成果价值"
}
```

`tone` 可使用 `coral`、`dark`、`lime` 或 `paper`；`size` 可使用 `large`、`small` 或 `wide`。

个人姓名、简介、从业经历和首页文案统一存放在 `网站信息.json`，修改后重新生成网站即可生效。

## 三、Linux 或云服务器直接运行

服务器需安装 Node.js 18 或更高版本：

```bash
unzip Yunjin-Portfolio-Standalone-v1.0.0.zip
cd Yunjin-Portfolio-Standalone-v1.0.0
chmod +x start.sh rebuild.sh
PORT=8080 ./start.sh
```

浏览器访问 `http://服务器IP:8080`。正式使用时建议用 systemd、Supervisor 或 PM2 保持进程运行，并通过 Nginx 配置域名与 HTTPS。

## 四、Docker 部署

进入解压目录后执行：

```bash
docker compose up -d --build
```

浏览器访问 `http://服务器IP:8080`。更新作品后先执行 `./rebuild.sh`，再执行：

```bash
docker compose up -d --build
```

## 五、直接部署为静态网站

`site` 文件夹就是最终静态网站，可以直接复制到 Nginx、Apache、宝塔面板、对象存储静态托管或其他云平台的网站根目录。

压缩包内提供了 `nginx.conf` 示例。使用前请根据服务器实际路径修改：

```nginx
root /var/www/yunjin-portfolio/site;
```

## 六、端口与防火墙

- Windows 默认端口：`4173`
- Docker 默认映射端口：`8080`
- Linux 可通过环境变量修改，例如 `PORT=9000 ./start.sh`
- 云服务器需在安全组或防火墙中放行对应端口；配置域名后通常只开放 80 和 443 端口

## 七、字体说明

网站使用 `Source Han Serif SC VF`，即思源宋体简体中文可变字体，覆盖 250—900 字重。字体按 SIL Open Font License 1.1 开放许可随包提供，相关说明位于 `site/fonts/source-han-serif-sc-vf`。
