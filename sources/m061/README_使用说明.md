# GeoScene OSM 三维场景生成器

GeoScene 是一套可在本地运行的地图选区三维建模工具。用户在地图上以矩形或圆形选择不超过 10 km² 的区域，程序会获取区域内的 OpenStreetMap 矢量要素、真实高程和配置的影像，并在 Three.js 中生成可交互的三维场景。

## 最简单的启动方式（Windows 10/11）

1. 将整个程序文件夹完整解压到本地磁盘，路径尽量不要过长。
2. 双击 `启动 GeoScene.cmd`（也可以双击全英文备用入口 `Start-GeoScene.cmd`）。
3. 第一次运行时，启动器会自动下载便携版 Node.js，并安装所需组件；根据网络情况可能需要几分钟。
4. 环境准备完成后，浏览器会自动打开 `http://127.0.0.1:3178`。
5. 后续再次双击时，会直接复用已经配置好的环境。

启动窗口不要关闭。关闭启动窗口后，本地服务会停止。新版启动入口只包含传统 Windows 命令行能够稳定识别的 ASCII 指令，实际安装流程由 PowerShell 执行，可避免不同系统区域设置导致的中文乱码和命令被截断。

## 使用流程

1. 输入城市或地标名称定位，也可以直接缩放、平移地图。
2. 点击“矩形框选”或“圆形圈选”，在地图上拖拽选择区域。
3. 选区面积必须大于 100 m² 且不超过 10 km²。
4. 首次使用建议点击右上角设置按钮，检查 OSM、影像和地形服务。
5. 点击“生成三维场景”。程序依次获取 OSM、地形、影像并生成模型。
6. Three.js 预览中：左键旋转、右键平移、滚轮缩放，双击要素查看 OSM 属性。
7. 可导出 GLB、FBX 模型包，或者包含源数据与元数据的完整项目包。

## 数据源配置

### OSM

默认自动尝试多个公开 Overpass 节点。工具请求的是框选范围内的原始 OSM 数据，不会批量抓取 OpenStreetMap 公共地图瓦片。

### 高精度影像

支持：

- XYZ：服务地址需包含 `{z}`、`{x}`、`{y}`，例如 `https://example.com/{z}/{x}/{y}.jpg`。
- WMS：输入 GetMap 服务地址和 LAYERS 名称，程序自动添加范围、宽高和 EPSG:4326 参数。

默认 Esri World Imagery 只作为开箱预览源。公开可浏览不等于允许再分发或用于模型贴图。只有在确认影像服务条款允许导出后，才勾选“我确认该影像许可导出为模型贴图”。未勾选时，影像可用于预览，但不会写入 FBX 或完整导出包。

### 地形

默认使用 Mapzen Terrarium / AWS Open Data 高程瓦片。可调整采样层级、网格精度和垂直夸张倍数。如果地形服务临时不可用，程序会回退到平面地形并明确提示，OSM 建模仍可继续。

## OSM 属性到三维效果的映射

| 图层 | 主要标签 | 建模方式 |
| --- | --- | --- |
| 建筑 | `building`、`building:part` | 面挤出为三维建筑 |
| 道路 | `highway`、跑道/滑行道 | 按道路等级、车道数或 `width` 生成不同宽度 |
| 水系 | `natural=water`、`waterway`、水库等 | 水面或按水系等级生成带宽线 |
| 绿地 | `leisure=park`、森林、草地、花园等 | 贴合地形的绿色语义面 |
| 轨道 | `railway` | 按铁路、地铁、轻轨类型生成带宽线 |

建筑高度优先级：

1. `height`；
2. `building:levels × 默认层高`，并叠加 `roof:levels`；
3. 根据 `building` 用途采用内置默认值；
4. 仍无法识别时采用“默认楼层 × 默认层高”。

## 导出格式

- GLB：推荐用于 Web、Three.js、Blender、Unity、Unreal 等流程，支持完整材质和嵌入纹理。
- FBX：导出为 FBX 7.4 ASCII，Y 轴向上、单位为米。FBX 包同时包含许可允许的 `texture.jpg`、导入说明和元数据。
- 完整项目包：包含 GLB、FBX、OSM GeoJSON、高程网格、元数据和预览图。

模型采用局部坐标，X 轴向东、Y 轴向上、Z 轴向南，原点对应选区中心的 WGS 84 坐标。精确原点、高程基准和数据来源记录在 `metadata.json` 中。

## 数据许可

- OpenStreetMap 数据采用 ODbL 1.0，界面和导出包保留 `© OpenStreetMap contributors` 署名。
- 高程许可与署名以配置的数据服务为准。
- 影像许可由影像服务提供者决定；使用者需要自行确认下载、裁剪、再分发和模型贴图权利。

## 常见问题

### 第一次启动很慢

启动器需要下载便携 Node.js 并安装组件。完成后会在程序目录生成 `.runtime` 和 `node_modules`，后续启动不再重复下载。

### 浏览器显示 WebGL 不可用

请使用新版 Chrome、Edge 或 Firefox，并在浏览器设置中开启硬件加速。地图、OSM 获取和地形处理不依赖 Three.js 预览，但导出前建议在支持 WebGL 的浏览器中检查模型。

### 影像或地形加载失败

公开服务可能限流、维护或限制跨域。工具通过本地服务转发请求，但仍需遵守服务条款。可以在设置中替换为其他合法的 XYZ/WMS/Terrarium 服务。

### OSM 获取超时

缩小选区，或在设置中切换 Overpass 节点。高密度城市的 10 km² 数据量可能很大，建议以 1–3 km² 为主。

### OSM 返回 HTTP 400

新版会把地图横向循环产生的经度（例如大于 180°）自动换算到标准经度范围；跨越 180° 经线的选区会自动拆成两个合法查询，并在获取后重新拼接坐标。如果从旧版页面升级，请强制刷新浏览器后重新框选。

### 启动窗口出现乱码或“不是内部或外部命令”

请使用本压缩包中的新版 `启动 GeoScene.cmd` 或 `Start-GeoScene.cmd`。启动文件必须与 `scripts` 文件夹保持原有相对位置，不能只把 `.cmd` 文件单独复制到桌面。若曾运行旧版，可删除程序目录下的 `.runtime` 后重新双击启动；无需管理员权限。

### Windows 安全提示

启动器是可阅读的 `.cmd` 脚本，不会请求管理员权限。它只会在当前程序目录安装便携运行环境和依赖，并启动本地端口 3178。
