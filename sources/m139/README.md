# 昆冶数字孪生一体化实训基地

Static Three.js concept prototype. Dist has no external runtime dependencies. Original hall geometry is retained; renovation is a separate group. Dimensions are photo-based assumptions, not measured. IoT values are demonstrative only.

- `data.js`: authoritative eight-zone, five-major, 32-task, four-project catalogue.
- `original-scene.js`: existing hall structure and original facilities.
- `upgrade.js`: renovation geometry and two reversible furniture configurations.
- `app.js`: 3D navigation, 2D fallback, task filters and simulated monitoring states.

Run `npm run build` for syntax checks. Preview via `sites-preview start .`. WebGL is required for 3D; unavailable environments show an explicitly labelled interactive floor plan. No sensor or commercial platform integration is claimed.
