# GeoModel 通用三维模型浏览器

GeoModel 是一个以 Three.js 为核心、完全在浏览器本地解析文件的通用三维模型查看工具。它是独立工具，不依赖 GeoScene 场景生成器；GeoScene 导出的 FBX、GLB 可以直接拖入本工具检查。

## Windows 一键启动

1. 先把下载的 ZIP **完整解压**到本地可写目录，不要在压缩包预览窗口中直接运行。
2. 双击 `启动 GeoModel.cmd`（英文入口为 `Start-GeoModel.cmd`）。
3. 首次启动会自动检查 Node.js。电脑上没有合适版本时，程序会把 Node.js 下载到本目录的 `.runtime` 文件夹，然后自动安装依赖并打开浏览器。
4. 后续启动会复用已安装环境。关闭启动窗口，或双击 `停止 GeoModel.cmd`，即可停止本地服务。

启动器不会修改系统 Node.js、不写系统目录，也不需要管理员权限。首次安装需要能访问 Node.js 与 npm 的公开下载服务。

## 支持格式

| 类别 | 格式 | 说明 |
| --- | --- | --- |
| 实时/交换 | GLB、GLTF | 支持 Draco、Meshopt、动画、材质及外部纹理；GLTF 请连同 `.bin` 和纹理一起选择 |
| DCC | FBX、OBJ + MTL、DAE | 支持对象层级和常见材质；外部贴图需一起选择或使用“打开文件夹” |
| BIM | IFC | 通过 web-ifc 在浏览器内读取构件几何、Express ID 和常用属性 |
| CAD | STEP / STP、IGES / IGS、BREP / BRP | 通过 OpenCascade WebAssembly 在本地三角化；大型装配需要更多内存和时间 |
| 网格/打印 | STL、PLY、3MF | 支持二进制/文本网格及常见顶点色 |

## 主要功能

- 鼠标旋转、平移、缩放，透视/正交投影与六个标准视图
- 模型对象树、名称/类型/IFC ID 搜索、显隐、聚焦与隔离
- 对象基础属性、IFC 构件属性、模型顶点/三角面/尺寸统计
- 两点距离测量、水平剖切、透明度、线框、阴影、网格和坐标轴
- 模型方向 90° 校正、GLTF/FBX 动画播放、PNG 截图
- 多文件选择、完整文件夹选择和拖放导入

## 操作提示

- 左键拖动：旋转；右键拖动：平移；滚轮：缩放。
- “选择对象”模式下单击构件，在右栏读取属性。
- “测量”模式下依次点击模型上的两个点。
- STEP、IFC 等大型文件会在当前电脑上解析，期间页面显示处理进度；建议使用 64 位最新版 Chrome 或 Edge，并预留足够内存。
- 文件仅在当前浏览器进程中处理，本工具不会主动上传模型内容。

## 开发运行

要求 Node.js `>=22.13.0`：

```bash
npm ci
npm run dev
```

生产验证：

```bash
npm run lint
npm test
```

## 技术组成

- Three.js r185：渲染、交互和通用格式加载
- web-ifc：IFC 几何与属性解析
- occt-import-js / OpenCascade：STEP、IGES、BREP 三角化
- Vinext / React：应用界面与托管构建

本项目使用到的第三方库分别遵循其原始开源许可证。导入的模型及纹理版权仍归文件提供者所有。
