# 宝石小掌柜 · 3D 奇妙工坊

依据《宝石小掌柜 PRD V1.0》开发的儿童经营游戏。2.0 将采购、加工、交付接入可行走的三维小镇，保留原有的算术、库存和成本规则。

## 游玩

打开 `dist/index.html`，或打开在线版本。所有脚本、模型和图形资源都已内嵌，无需 CDN、安装或联网。首次选择昵称、头像和教学模式；旧版的三个本地存档仍可继续。

- WASD / 方向键移动，点击地面或店铺自动寻路，靠近店铺按 E 互动；手机使用左下角摇杆。
- 俯瞰 / 跟随两种镜头，右键拖动环顾、滚轮缩放；可切换白天和暖夜；跟随视角中遮挡角色的小屋会自动淡化。
- 原石集市：走到柜台选石、旋转观察、计算预算后购买，角色带着原石前往切割工坊。
- 切割工坊：确认费用后沿虚线划过，切割工具随操作移动；划偏可重试，也可辅助完成。
- 手作工坊：选配方、款式、数量与名字；按住三维宝石约 4 秒打磨，再点击三枚金色配件逐个装配，最后确认完成。
- 宝石小铺：带着成品前来，整单交付给顾客，查看收入、成本与利润。

未完成打磨或装配时，退出或刷新不会扣除材料、加工费；手作进度会重置，可从已保存的方案重新开始。辅助操作供触控困难的玩家使用，结算结果相同。

## 保留的经营内容

四种原石、八种配方、八个可重接订单；材料分组、跨批次成本、整单出售、三级算术提示、免费帮工、留影图鉴、账本、成长徽章、装饰、程序合成音效与音乐。

设置中可管理三个存档、难度、音效和 JSON 备份。在线网址与本地 HTML 使用各自浏览器存储，可通过备份迁移。金币、材料及费用均为游戏数值。

## 架构与构建

- `core.js`：纯业务规则、校验、原子交易快照。
- `app.js`：界面、场景流程、存档租约、Web Locks、备份。
- `world3d.js`：Three.js 场景、动画、Raycaster 交互、镜头和工作台。
- `models3d.js`：原创角色骨架、四类小屋、工具台、原石、配方成品和植被。
- `navigation.js`：A* 寻路、碰撞及连续行走。
- `software3d.js`：无 WebGL 时自动使用的 Canvas 三维兼容渲染，共享同一场景、模型、摄像机和拾取逻辑；几何细节、光照和遮挡精度较低。
- `vendor/`：Three.js r180 原始模块及 MIT 许可。构建时合并为内嵌脚本。
- `art.js`、`town.svg`：UI 插图与备用二维画面；`style.css`、`world.css`：桌面与移动布局。

构建：`python3 build.py`。测试：`npm test`。输出只有一个可独立打开的 `dist/index.html`，约 2.25 MB。

## 验证与限制

规则测试覆盖 17 组经营场景：教程余额、八种配方连续经营、部分加工、跨批次、重复交易、失败回滚、算术历史、账本和损坏备份等。新增测试覆盖真实四站之间的寻路与碰撞、94 种三维资产组合、角色关节、配件中心点击、旧存档兼容和无效坐标拒绝。

本次在预览浏览器完成了采购、鼠标划线切割、按住三维宝石打磨至 100%、点击三枚配件、制作、交付全流程；余额依次为 1000→820→780→700→1120。验证了取消制作不扣资源、WASD 位移、跟随镜头及刷新后的存档恢复。

预览浏览器禁用 WebGL，因此本次实际画面与交互检查使用兼容三维渲染；WebGL 渲染在支持的浏览器自动启用，尚未完成目标手机 / GPU 的实机帧率和光影验证。390 像素宽嵌入视口用于手机布局检查，不代表真实触屏设备测试。本版是可玩的三维原型，尚无自定义定价、云同步、联网协作或真实儿童试玩评估。
