# 校园部署与数据接入设计

此文件描述后续工程边界，本版未实现服务器API或实车适配器。

## 学习与考核服务

服务端负责账号与授课权限、任务分发、试卷版本、随机选题、绝对截止时间、事件幂等、事务提交及审核日志。客户端事件包括sessionId、sequence、action、target、result、time与measurement。服务端应从自身时钟和规则计算成绩，不能信任客户端分数。

任务、评分和资料使用不可变版本。发布更新仅影响新会话；历史工单保留原始快照。提交重试使用相同幂等键，返回已有记录。

## 只读设备字段

```json
{
  "deviceId": "由学校登记的实际设备编号",
  "vehicleVersion": "经授权的车型与资料版本",
  "field": "按适配器字段字典确定",
  "value": 0,
  "unit": "按字典确定",
  "source": "live",
  "observedAt": "设备采样时间",
  "receivedAt": "平台接收时间",
  "quality": "valid"
}
```

live、simulation、replay分别表示实时、仿真和回放。失联后显示最后有效时间，不把冻结数据呈现为实时。字段精度、刷新频率、协议授权与诊断访问权限按实际设备联调确认。

本版规则层的测点与组件ID可作为映射起点，但示例数值与EDU故障码不能当作量产车型规范。任何物理写入、故障设置或高压硬件控制都须在独立设备方案中设计与验收。
