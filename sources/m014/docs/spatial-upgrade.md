# 三维交互升级说明 V1.1

日期：2026年10月16日。

## 已开发的三维交互

默认入口改为三维实训工坊。模型由7个教学总成、12个电池模组、8颗独立固定螺栓、三类教学连接器、支撑工位与仪表构成。车辆采用中性教学结构，不指向特定量产车型。

场景支持旋转、缩放、平移、预设视角、结构展开、透明车身、水平剖切、ECU温度示例映射和部件选择。故障修复与复电状态驱动线缆色彩及供能流动示意。温度映射表示教学采样信号，不代表独立测温结果。

## PACK01 动力电池包三维拆装

1. 完成防护、区域、仪表检查、模拟关闭与隔离。
2. 在高压验电教学测点连接红黑表笔，采集有效验电证据。
3. 使用举升托架放置并确认支撑。
4. 使用对应工具解除高压、低压采样与教学冷却连接。
5. 使用拆装套筒，逐颗拆下8颗固定螺栓，模型中的螺栓进入零件盘。
6. 受控下放电池包，完成离车检查。
7. 举升对位，使用紧固工具逐颗完成教学紧固。
8. 恢复三类连接，移除支撑并确认。
9. 完成装配恢复确认、模拟复电和验证，提交工单。

点击三维对象与同名操作清单调用同一规则引擎。状态改变后才更新模型，不直接以动画判定完成。首次危险尝试保留唯一风险分类，全部尝试保留日志；错误工具与不满足前置条件的动作不改变对象状态。

本任务使用专属评分：安全30、验电15、拆卸25、回装20、验证10。考试关键安全门槛延续原规则；通过还要求完整回装和恢复验证。教师复核不替代完成门槛。诊断任务继续使用原有评分。

## 三维仪表

直流和电阻测量需要两支表笔接到当前测点的不同端子。既可点击三维端子，也可用等价端子按钮连接。直流表笔反接显示负值；换测点后不能复用其他测点的接线。采集记录保存接线方式与3d-probe交互来源。

表笔端点跟随当前对象运动；线缆更新复用几何缓冲。诊断仪与独立测温不要求表笔。所有值和测点坐标均为教学示例。

## 验证与适用边界

规则和DOM流程测试包含完整拆装、危险动作拦截、错误工具、重复计分、表笔极性、恢复、旧流程回归。真实Three.js几何测试验证对象存在、射线击中、拆装坐标变化、回装恢复及线缆端点跟随。

当前环境没有Sites支持的浏览器验收能力。本轮没有启动预览或使用替代浏览器路径。因此三维渲染画面、触屏手感、GPU帧率及目标机房性能仍待实机验收。几何和DOM测试不能证明这些指标达标。

当前仍是浏览器本地教学验证版。真实车型、维修参数、设备接入、服务端身份与跨设备同步按初版PRD后续校园部署范围实施。
