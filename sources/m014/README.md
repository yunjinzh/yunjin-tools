# 新能源汽车虚拟仿真维修平台

面向高校新能源汽车相关专业的虚拟维修教学验证版。覆盖四个课程域、12个知识单元、12道课程自测题、九个任务，以及学习、实训、考核、工单、教师布置与复核流程。

## 使用与运行

打开发布地址进入三维实训工坊，可选择电池包拆装或诊断任务。初次进入没有实际成绩；可在教师工作台显式切换示例视图。

静态文件全部位于 `dist/`。在任意 HTTP 静态服务器上托管该目录即可。ES 模块需要 HTTP 服务，不应通过双击本地 HTML 文件运行。举例：

```bash
python -m http.server 8000 --directory dist
```

然后访问 `http://localhost:8000`。该命令是本地运行示例；本次交付未在当前环境启动浏览器预览。

源代码无需编译即可运行。Three.js、控制器、字体及文档随静态文件交付，不依赖运行时外部 CDN。

## 学生体验顺序

1. 在三维工坊观察整车、三电和底盘，再选择电池包拆装或课程诊断。
2. 在虚拟实训选择引导或独立模式。
3. 完成安全准备；选择万用表直流档和高压验电测点，连接红黑表笔至不同端子，再采集读数。
4. 诊断任务可自主选择测量路径。拆装任务需选择机械工具，直接点击三维连接器、固定螺栓与支撑，或使用等价操作清单。
5. 选择维修方案，恢复装配、模拟复电并验证。
6. 提交后查看分数、原始证据和补练建议。

考核中心按课程范围抽取任务，隐藏提示并持续计时。教师可建班、指定或随机布置任务、设置时长和通过线、检查实际记录并保存复核理由。

## 模块

- `assets/data.js`：课程、知识、自测、任务、工具与测点定义。
- `assets/engine.js`：操作前置条件、读数、日志、证据与评分。
- `assets/store.js`：本地存储、备份校验、班级布置与CSV导出。
- `assets/model.js`：独立三维总成、螺栓、连接器、仪表、表笔与工位模型。
- `assets/scene.js`：真实射线拾取、镜头、剖切、标注与控制。
- `assets/mechanics.js`：电池包拆卸和回装状态机与评分证据。
- `assets/workshop-ui.js`：三维工坊与操作面板。
- `assets/fallback.js`：WebGL不可用时的教学结构图。
- `assets/app.js`：页面、工位交互、工单、教学和计时。
- `docs/`：PRD、验证与集成说明。

## 验证

```bash
pnpm install
node --test tests/*.test.mjs
node scripts/check-assets.mjs
```

规则与DOM检查详见 `docs/validation.md`。DOM检查采用明确的无WebGL模式，不代表三维渲染或目标机房的图形性能已经通过验收。

三维升级说明与专项评分见 `docs/spatial-upgrade.md`。初版PRD保留为V1.0，新增对象级交互在升级说明中记录。

## 版本边界

本版是可运行的浏览器本地教学验证系统。车辆是中性EDU EV结构，所有初始读数、故障码和参数均为教学示例。角色切换演示流程，数据不会跨设备自动同步，不提供生产鉴权、服务端监考、实车连接或高压作业认证。

正式校园部署应接入服务端账号、班级、审计与备份，并按获授权车型资料校核模型、参数和安全规则。采购建议的40并发与帧率指标尚未进行实测。
