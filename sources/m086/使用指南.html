三步开始

01

完整解压

把压缩包完整解压到磁盘，例如 D:\ShiguangPhoto。保留 runtime、models、web 等子目录。不要直接在压缩软件里运行。

02

运行启动程序

双击 start.cmd 或 启动拾光智能相册管理系统.cmd。浏览器会自动打开本机相册。运行环境和模型已随包提供，无需手动安装 Python。

03

添加照片目录

点击“添加照片目录”，浏览选择文件夹，或粘贴完整路径。默认读取子目录，先建缩略图，再整理人物。

界面由本机服务打开。正常地址为 http://127.0.0.1:8765/，端口占用时会依次使用后续端口。保留启动窗口即可后台处理；关闭网页不停止任务，关闭启动窗口后可在下次启动继续。

适用环境：Windows 10/11、x64处理器，建议使用桌面版 Chrome 或 Edge。Windows ARM、32位系统和旧版浏览器未纳入本包适配范围。首次处理耗时由原图数量、分辨率、硬盘和CPU决定。

日期精度与时间线

可填写 2018、2018-08、2018-08-12 或 2018-08-12 15:30:00。仅指定年份的照片归入该年的“月份待补充”，并在详情中保留年份精度。批量校正存于索引，不改写原图EXIF。时间线按照片记录的本地日期分组，原始时区偏移另行显示。

支持的文件

JPEG、PNG、WebP、BMP、TIFF、GIF首帧、HEIC/HEIF和AVIF通过随包解码器读取，具体文件是否可解码以日志为准。RAW格式会登记并提示导出JPEG/TIFF副本。符号链接和目录联接会跳过；相册数据目录自动排除。

人物整理

  1. 等待本机分析：缩略图处理完成后，后台使用YuNet检测人脸，再使用SFace提取特征并聚合。同一张合影可以出现在多个对应人物相册中。
  2. 命名人物：进入“人物”，点击人物卡片右上角“···”，填写名称。可标记为常用人物。
  3. 合并分组：勾选属于同一人的多个分组，点击“合并选中人物”，选择保留的分组。
  4. 拆分错误归类：进入某个人物的照片，开启“选择照片”，选中错误照片后点击“人物归属”，分配到其他人物或新建人物。
  5. 确认模糊结果：在“待确认人脸”中查看建议，确认或选择正确归属。相似度是模型分数，不是正确概率。
  6. 在详情中纠错：每个人脸都可以确认、移到待确认、更改归属或设为人物头像。
  7. 手动补录：打开照片，点击底部“手动补录人脸”，拖动框选区域，再选择人物。
  8. 找合照：在人物页勾选多人并点击“查找合照”，或在筛选中切换“同时出现 / 任一出现”。
人物名称由你填写。系统以视觉相似性分组；侧脸、遮挡、跨年龄及低清晰度照片需要人工检查。已人工确认的归属和排除记录会保存。重新分析时，能够匹配原区域的确认结果会沿用；原文件内容发生大幅改变时需重新核对。

保存、备份与迁移

位置用途
你添加的原图目录原始照片，按只读方式访问。
工具目录 / data / library.sqlite3目录、时间、人物、标签、收藏、相册、纠错与日志。
data / thumbs、previews、faces缩略图、预览图及人物头像，均为真实文件。
data / exports原图导出的临时ZIP和原尺寸显示副本。
data / backups恢复操作前自动保留的数据库副本。

索引备份：设置 → 导出索引备份。备份包含数据库、人脸特征、人工整理和相册；不包含原图与缩略图。原始照片需要另行备份。

恢复：设置 → 恢复索引备份 → 选择备份ZIP。当前索引会先自动备份；恢复后任务暂停，缩略图缓存清空。检查“照片目录”，必要时重新关联，然后点击“继续”重建预览。

更换数据盘：安全退出程序，把完整data目录复制到目标位置，例如 E:\PhotoIndex。编辑工具目录中的 data-location.txt，只写入这一行完整路径，然后重新运行start.cmd。空文件表示使用工具旁的data目录。

移到另一台电脑：复制完整工具文件夹以及原照片，或使用索引备份恢复。原照片路径变化后重新关联。网络资源盘和移动硬盘断开时，已有缩略图仍保留，原尺寸查看和导出需要重新连接原图。

问题排查

现象处理方式
双击HTML提示连接本机服务从完整解压的工具目录运行start.cmd；使用程序自动打开的本机网页。
启动窗口一闪而过或启动失败运行diagnose.cmd / 启动诊断.cmd，查看diagnostics.txt和startup-error.log。确认runtime与models目录完整，使用Windows x64环境。
目录选择窗口没有出现切换任务栏查看系统选择窗口；也可直接把资源管理器中的完整目录路径粘贴到输入框。
已添加照片但还没有人物先查看底部是否仍在生成缩略图；确认设置中已启用人脸分析。完成后检查日志的人脸阶段。
照片打不开查看是否原目录未连接、文件损坏、格式暂不支持或路径过长。解决原因后在日志或设置中重试失败文件。
新增照片没有出现打开“照片目录”，点击“扫描新增与变化”。本版使用主动扫描，不持续监控文件系统。
更改尺寸后旧缩略图没有变化先保存设置，再打开设置点击“重新生成缩略图”。人物、标签和相册保持保留。
处理占用资源，希望稍后继续点击底部“暂停”；当前单张照片处理完成后暂停。点击“继续”恢复，也可安全退出并在下次启动继续。
需要退出程序设置 → 安全退出程序；或在启动窗口按Ctrl+C。网页关闭后服务仍继续运行。
