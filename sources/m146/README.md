# 字野长路 · 原卡画廊 V3
Three.js r170 + 双渲染后端。摆脱原岛屿视角，约 6.6 公里真实世界空间前行；414 张原卡、8类生境、每段最多4张字卡，全程107段。全屏HUD、连续行进、实体路牌、原图观察、回忆练习、图鉴与本机进度均离线可用。来源保留原编号/读音，不改动原书，未逐张完成教学终审。
- dist/index.html：浏览器入口；无需服务端。
- dist/road.js、scenery.js、soft3d.js：透视相机、流式道路、主题模型、轻量几何绘制。
- dist/app.js：路线表、暂停与全屏、现有图鉴兼容与学习界面。
- dist/data.js、cards/：414张实际字卡的元数据与压缩副本。
- node test.mjs：资源/数据/HTML ID/谜题/路线结构验证。
- V1 已留在上一个已保存的网站版本与独立离线压缩包。

V3 路侧直接铺原始 WebP 画卡，2.7×3.599米，保留全幅 760:1013 形状。原卡图片/拼音/汉字无需点击。点击只用于可选放大或认读练习。卡片按窗口预取，上限12张纹理、3项同时加载。离线包使用按卡经典脚本承载相同 WebP 数据，避免 file URL 上传 GPU 纹理的同源限制。

构建：python build-road-offline.py <output.zip>；运行 node tests/original-card-textures.cjs 与 node test.mjs。V1 / V2 都已保留。

V4：修正路旁可见卡的HUD定位，改为相机投影的可读区域；新增上一张、路线精确预览、停步/步速恢复；图鉴分页、来源返回、答题反馈与键盘焦点改善。验证见 tests/ 与单独的 UX 验收报告。前3个已保存版本和离线包继续保留。
