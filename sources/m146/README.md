# 字野长路 · 全屏道路版
Three.js r170 + 双渲染后端。摆脱原岛屿视角，约 6.6 公里真实世界空间前行；414 张原卡、8类生境、每段最多4张字卡，全程107段。全屏HUD、连续行进、实体路牌、原图观察、回忆练习、图鉴与本机进度均离线可用。来源保留原编号/读音，不改动原书，未逐张完成教学终审。
- dist/index.html：浏览器入口；无需服务端。
- dist/road.js、scenery.js、soft3d.js：透视相机、流式道路、主题模型、轻量几何绘制。
- dist/app.js：路线表、暂停与全屏、现有图鉴兼容与学习界面。
- dist/data.js、cards/：414张实际字卡的元数据与压缩副本。
- node test.mjs：资源/数据/HTML ID/谜题/路线结构验证。
- V1 已留在上一个已保存的网站版本与独立离线压缩包。
