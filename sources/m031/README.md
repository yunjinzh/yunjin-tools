# 三十六计 · 智谋沙盘

中国古典谋略的公众教学网页。六套、36计，每计三个可操作阶段，共108个阶段；使用 Three.js 三维地形、可移动队伍、守备视野、部署物与动态连接表达机制。

## 运行

静态入口为 `dist/index.html`。可直接用浏览器打开，所有运行资源均在 `dist` 内，不依赖外部字体、CDN、账户或接口。通过网址后的 `#1` 至 `#36` 定位计策。

标题使用随站点加载的 Adobe 思源宋体简体中文 2.003 字库，包含400、500、600三种字重。页面字库已按当前文字裁剪，字体许可与来源见 `dist/fonts/OFL.txt` 和 `dist/fonts/NOTICE.md`。

## 功能

- 六套导航与36计总览；每计独立局势、节点、行动和特定错误反馈。
- 可旋转、缩放、俯视与全屏查看河谷、山地、营地、城池、林地和会谈场景。
- 点击队伍规划路点，或直接拖动队伍移动；拖放部署、拖动连接、资源筹码分配都对应实际位置与条件。
- 行动指令在场景内和下方均可使用；行动需要实际移动或等待对方响应，暂停、单步与三档速度便于观察。
- 精力、警戒、围攻压力、补给、航行习惯与撤离后队形成实际的代价、失败条件和延迟结果。
- 暗度陈仓与金蝉脱壳要求维持掩护；关门捉贼有可暂停的出逃窗口；釜底抽薪会逐渐耗尽前沿供给。
- 11个场景包含实时参数比较：等待、窗口、资源、偏移、开口、诱因、混乱、声势、疑虑、代价。
- 对方所见、阶段进程、撤销、重置与代价/因果复盘；撤销同时恢复真实位置、资源、警戒及局势时间。
- 连环计断环会撤销后续条件；空城计在疑虑前提不足时无法推进。
- 桌面、平板与手机样式；语义按钮、键盘操作、反馈播报与减少动态效果支持。三维启动失败时使用平面推演。

## 内容依据与边界

计名、六套和顺序：商务印书馆2015年《孙子兵法·孙膑兵法》官方附录目录；中央电视台2007年《战争中的36计》节目页交叉核验。

两文本区别：共产党员网2019年《品读中华经典》孙子兵法（详解版）。完整出处与异写列于页面“版本与内容依据”。

释义、匿名场景、数值阈值、位置和结果为现代教学设计，不是历史复原或统计规律。图像为原创生成插画。作者与确切成书年份资料不足，页面原位标明事实断层。

## 验证

- `node scripts/check-gameplay.cjs`：36个场景与108个空间行动全流程，以及撤销、自由移动、暂停、掩护中断、资源锁定、航线、逃离、补给、视野、依赖连接与后队撤离。
- `node scripts/check-ui.cjs`：三维桥接和降级模式各36个场景；工具输入原子性、连环计断环撤销、滑杆/回合同步。
- `node scripts/check-scene3d.cjs`：使用真实 Three.js 数学与几何的 CPU 场景检查覆盖36场景、144个状态、几何有限值、感知方向、镜头投影以及切换/释放；renderer、OrbitControls 与 DOM 是模拟接口。
- 此执行环境没有可用的静态站点浏览器预览；真实 WebGL、GPU、画面、触屏和原生 WebMCP 尚未检查。

## 实现

`data.js` 存放场景与教学内容；`engine.js` 校验阶段因果；`game-core.js` 管理空间行动、响应与代价；`scene3d.js` 构建三维场景；`app.js` 驱动界面与可选 WebMCP 工具。工具启动实时行动后需再次读取状态确认是否完成。网页不保存用户操作，不采集个人数据。

Three.js 与 OrbitControls 固定为官方 r160，随站点本地加载，不依赖 CDN。`dist/vendor/three-r160.min.js` 为官方 classic build；OrbitControls 从同版官方模块转为绑定 `window.THREE` 的普通脚本，算法保持原样；MIT 许可见 `dist/vendor/LICENSE-three.txt`。来源：`https://github.com/mrdoob/three.js/tree/r160`。
