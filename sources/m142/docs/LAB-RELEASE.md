# 三维实训增强版 V1.0

发布日期：2026-11-16。新增入口 `/lab`，原工作台 `/` 保留。原工作台发布版本 2 的源码基线为 `0e7ff07e36704122cbd4dd4c53e01afea67b9d79`；此次未修改根页面、全局样式、正式审核 API、政策与任务数据，未修改原 V3.0 Word 方案。

## 已实现

| 模块 | 关联原任务 | 可操作内容 |
|---|---|---|
| 航线与采集 | T03、T07 | 航高、重叠率、航线播放、漏拍情境、几何覆盖及GSD估算 |
| 点云配准 | T08、T13、T15 | 合成点云位姿、异常点、已知同名点刚体求解、独立检查点RMSE |
| 更新方案对比 | T22、T23、T24 | 固定视点切换A/B、廊架标高、通视求交、路径与教学工程量 |
| 物联运维演练 | T26、T28、T29、T30、T35 | 三维设备点选、阈值、连续采样、离线/越限故障、派单—恢复—处置—复核 |

场景使用 Three.js。优先 WebGL；无 WebGL 时使用 Three.js SVGRenderer 保留相机和几何交互，简化光影。所有场景为程序生成的合成教学样例；没有导入校园实测模型，没有接入真实传感器。

练习快照保存参数、计算结果、反思与日志；必须填写判断后才允许保存。最近12份仅存此浏览器，可导出真实XLSX、JSON；场景可导出带教学模拟水印的PNG。快照不调用正式审核写入API，不会变成已确认验收证据。原工作台Word/Excel导出保持原逻辑。

## 走查与验证

- 四模块逐项走通；参数变化与场景/数值联动。
- 点云固定同一观测数据，使用80%同名点拟合，20%独立检查；剔除已标记异常后独立RMSE示例约0.049m，仅为合成数据误差。
- IoT恢复/改阈值须重新采样，旧读数不能用于处置；处置后再次异常退回处理中；离线不能复核关闭。
- 真实浏览器验证鼠标旋转、复位、设备点选、场景截图、保存必填校验、刷新恢复、Excel/JSON下载、原任务卡展开。
- 390px视图验证移动布局和保存弹窗，触屏提示、44px按钮、草案标识可见。此为窄视口测试，不等同于物理手机测试。
- 测试浏览器禁用WebGL，因此实际画面及交互测试使用SVG兼容模式；WebGL路径通过类型和生产构建检查，未在本次浏览器中完成GPU画面验证。
- 数学与状态回归：`node scripts/lab-model.test.mjs`。
- 原工作台回归：`node scripts/audit-integrity.test.mjs`、`node scripts/audit-filters-exports.test.mjs`。
- 截图位于 `docs/screenshots/lab-desktop-final.jpg` 与 `lab-mobile-final.jpg`。
