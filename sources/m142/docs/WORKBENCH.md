# 数字教材政策合规与实训任务验收工作台

## 资料基线
- 昆明冶金职业大学_数字孪生实训基地建设方案_V3.0全过程深化版.docx，Library版本2（2026-11-11更新）。只读提取，不修改原文件。
- 国内数字教材建设政策要求与实施指南_2026年11月.docx，2026-11-15。
- 原方案任务、专业、页码与6类项目组合：lib/source.json。
- 政策官方来源核验：lib/policies.json。9份官网来源已核验；七部门数字教材专项意见仅高校引用，原文和准确日期待核。
- 政策与任务对应关系为分析草案；全部任务初始为草案，证据归档与验收确认均为0。

## 功能与数据
- 8个视图：工作总览、政策时间轴、合规矩阵、40项任务审查、资源清单、审核看板、证据档案、版本记录。
- 13类资源，8类源自方案第27页，其余为过程、能力、责任、更新和按需仿真证据。
- 服务器D1保存审查记录与版本；R2保存文件。浏览器无业务数据单点存储。
- 文件最大15MB，较大模型支持登记HTTPS受控链接。上传不代表审核通过；文件提供SHA-256校验并以附件下载。
- 私有站点；使用Sites身份保护API。学校/企业责任人字段为审查登记，不充当角色权限或电子签章。
- 正式验收需学校已确认流程、全局审查证据、全部适用资源已核对、校企责任人、审核人/日期/正式依据及结论。
- 流转只允许相邻阶段，必须填写经办人和变更说明。版本冲突拒绝覆盖。
- Excel为真实OOXML，含7个工作表。Word为真实OOXML，政策采用倒序时间轴段落，保留全部官方网址。

## 验证
- TypeScript检查通过；Vinext生产构建通过。
- 校验40项唯一任务、6类项目、254建议任务学时、原方案页码及专业映射。
- 自动测试：确认门槛、未归档拒绝确认、基础资源不得随意标为不适用、相邻阶段限制。
- Excel经openpyxl读取：7个表、40项任务、520条资源核对记录；Word经python-docx读取；所有OOXML部件XML解析成功。
- 浏览器验证：总览、任务筛选、任务详情、验收拦截、保存成功及版本留痕。
- 浏览器文件选择器会话中断，文件上传/下载未完成端到端验证；部署后使用实际附件时需核查归档反馈。仅本地预览产生QA记录，未部署到生产数据库。

## 维护边界
- 不把政策倡导、规划数量、建议学时、三维仿真或AI配置默认为强制验收指标。
- 国家智慧教育平台与规划教材规则先确认适用范围。
- 变更schema应追加迁移；已应用迁移不改写。
- 不将开发数据库、.wrangler、凭据或临时QA附件加入源码或发布归档。
