# 工作台视觉与交互可达性走查

检查日期：2026-11-16。对象为已发布 V1 工作台对应源码。此记录不构成学校审核结论。

## 本轮已修复

| 优先级 | 触发场景及用户影响 | 修复 | 验收方式 |
|---|---|---|---|
| P1 | 总览、筛选、表格、政策条款和抽屉大量业务文字为8—11px，长时间阅读费力 | 统一12px辅助、13px操作/表格、14px正文/表单；手机输入16px，保留仅装饰性英文眉题9—10px | 检查业务文字字号；在桌面和窄屏核对长标题 |
| P1 | 浅绿/灰文字与浅底缺少对比，草案、缺失、待核状态易被忽略 | 统一语义状态色和辅助文字色；正文/辅助/六类标签文字对比均≥4.5:1 | 对主题色进行WCAG相对亮度计算；浏览器检查色块和原有状态文字 |
| P1 | 32px图标按钮、20px任务编号链接与密集资源单元格不易点中 | 图标40px，手机44px；资源操作至少44px；任务编号至少38×28px；统一focus-visible | 键盘Tab及手机触控检查 |

| P2 | 现有CSS为巨型单行及尾部临时覆盖，同一组件不一致 | 建立文字、控制尺寸、状态语义tokens；合并同条件媒体查询与重复选择器；格式化为维护友好结构 | PostCSS完整解析，无语法错误 |

## 已提供的新增组件样式

- 筛选与定位：`.active-filters`、`.filter-chip`、`.table-scroll-hint`、`.quick-actions`、`.resource-toolbar`、`.resource-jump`。
- 状态与反馈：`.sync-notice`、`.inline-error`、`.toast.success`、`.toast.error`、`.overdue-summary`。
- 文件与连续处理：`.upload-mode`、`.selected-file`、`.modal-actions`、`.task-navigation`、`.action-link`。
- 表单支持`aria-invalid="true"`错误边框；表格/看板支持容器`focus-visible`。

## 检查证据

- PostCSS解析通过，并合并重复媒体查询和同选择器声明。
- 主题文字对比：正文12.32:1；辅助5.24:1；草案5.65:1；待核5.58:1；需补充5.18:1；已确认5.47:1；信息5.59:1；待规范5.61:1。
