# 观 · 无界画廊

交互式三维美术馆，包含六个相连且形状不同的无顶盖展厅、20 幅真实经典作品及中文导赏。

## 使用

- 全馆视角：拖动旋转、右键平移、滚轮缩放。
- 点击左侧展厅进入；拖动环视，WASD / 方向键移动，Q / E 转身。移动包含墙体与座椅碰撞检测。
- 点击作品打开讲解；可走近欣赏、上传本地图片、选择完整显示或等比裁切、恢复原作。
- 三种材质模式、画作显隐、昼夜灯光、默认线框的正投影平面图。
- 自定义图片经过等比缩小后存入当前浏览器 IndexedDB，不上传服务器，不跨设备同步。

## 开发

运行 `npm run dev` 开发，运行 `npm run build` 生成 Cloudflare Workers 兼容产物。

主要代码：`app/gallery.tsx` 界面，`app/gallery-engine.ts` 三维场景，`app/data/rooms.ts` 空间与动线，`app/data/collection.json` 作品及来源，`app/personal-art.ts` 本地布展。

作品均来自馆藏开放资源或 Wikimedia Commons；来源与复用信息逐项记录在作品数据和界面中。三维部分采用 Three.js，浏览器需支持 WebGL 2。

## 图片与文字编辑（第二版）

点击墙上的画作，在详情中选择“编辑图片与文字”。可以更换图片，选择完整显示或等比填充，并修改作品名称、作者、年代、原文名、材质、收藏来源、资料链接和最多 6000 字的讲解。保存后，详情、作品列表、悬停提示和墙边铭牌同步更新。也可只修改文字而保留原图。恢复原作会同时恢复图片与文字。

首次更换原图时，尚未改写的原作信息会清空，避免将原作的作者与解读用于新图片；已经写下的新文字会保留。旧版仅包含图片和文件名的个人布展仍可读取，并可补充作品信息。

## 本地 HTML

右上角“保存为本地 HTML”会把当前已保存的布展、20 幅原作、全部脚本和样式打包成一个 HTML 文件。用新版 Chrome 或 Edge 双击打开即可离线使用，无需安装运行环境。收藏资料的外部链接仍需要联网打开。

本地编辑优先保存至当前浏览器。再次点击“保存为本地 HTML”可把修改写入新下载的 HTML，便于备份、复制或发送。网页不能直接覆盖磁盘上的原 HTML。每次导出使用独立的本地保存标识，避免其他导出文件的缓存覆盖其中的内容。

在线版保留原有浏览器数据库；本地版与在线版的浏览器缓存独立。导出 HTML 可将当前在线布展带到本地。清除网站数据会删除浏览器保存的修改，已导出的 HTML 不受影响。

运行 npm run build 会先构建原站点，再生成 public/offline-gallery.html 并放入部署资源。生成器位于 scripts/build-offline.mjs，独立入口为 offline/entry.tsx；在线与本地版本使用相同的 Gallery 组件和 Three.js 引擎。
