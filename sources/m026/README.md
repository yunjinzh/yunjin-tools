# 智枢 · 工业数字孪生调度中心

工业互联网调度与决策售前交互 Demo。中文界面；Three.js 0.186.1；React 19；Vinext。所有业务数据、场景、控制、视频与通话均为模拟。程序化模型不对应任何真实工厂。

## 汇报顺序（约5分钟）

1. 调度一张图：旋转、缩放、俯视；资源搜索；设备/人员/车辆/视频/轨迹/环境图层切换；点选与空间定位。
2. 异常演练：注入 CNC-01 温度异常，确认告警，派发检修任务。
3. 决策支持：调整订单数量、检修时间、备用产能、交期；比较等待、切换备用、并行三种方案；查看公式与假设；下发模拟方案并导出计算结果。
4. 综合集控：模拟设备启停，经联锁确认，查看执行回执和审计记录；温度异常禁止启动。
5. 数据治理：对10条预置记录执行去重、单位转换、缺失及异常隔离，得到6条有效记录；可导出结果。
6. 事件回放：独立120秒预置演练，支持播放、倍速与跳转，联动异常状态、人员到场和车辆位置。
7. 同步诊断：点击同步指标查看采集、接收和显示时间戳、最大值、P95、超限计数；切换网络拥塞或暂停采集。

## 从第一性原理到架构

- 统一资产：每个设备、人员、车辆、机位使用唯一标识，并绑定本地米制坐标。真实投影、测绘坐标与变换矩阵待现场明确。
- 统一状态：遥测、三维图元、监测、控制回执共享状态；按序号拒绝旧样本覆盖新状态。
- 统一时间：设备事件时间、前端接收时间、画面更新时间分别记录；同步耗时与数据新鲜度分开显示。
- 统一闭环：异常 → 确认 → 派单/方案 → 模拟执行 → 恢复 → 审计。

实现：`lib/twin-model.ts` 为领域数据、清洗、方案计算、回放与对接契约；`components/twin/scene.tsx` 为三维场景；`app/page.tsx` 为状态管理与业务交互。

## 能力边界与真实接入

- 当前采集为1.5秒定时生成样本，正常传递队列450–960ms，拥塞演示3450ms。
- 三维页在 renderer.render 返回后记录更新回执；其他业务页使用参数画面更新回执。此为软件帧提交测量，不包含屏幕物理显示延迟。真实单设备虚实同步≤3秒尚未验收。
- 采样、接收、渲染共享浏览器时钟，仅模拟链路耗时；应接入真实设备/网关/后端，建立跨端时钟校准、trace_id、序号、质量码、缓冲与断网恢复机制后验收。
- 视频为独立三维机位；通话仅流程模拟；控制仅更新浏览器状态。接口契约可从界面下载，设计端点尚未实施为服务。
- 决策为简化瓶颈工序计算。基准主线30件/h、备用24件/h、切换8分钟；未建模完整排程、运输、良率、在制品波动与不确定性。
- 当班累计产量与流程产量是固定演示基线；运行状态、模拟能力、温度、负载、告警和指令会随交互更新。
- 实时与预置回放相互隔离；回放不等于当前会话历史。刷新会重置会话。
- VR入口使用WebXR，仅在浏览器、设备、HTTPS和权限支持时可用；本次未使用头显验收。
- 响应式布局适配桌面与手机；实际浏览器/WebGL交互与视觉QA本次受可用预览能力限制，未完成。

## 开发与核验

```
pnpm install
pnpm dev
pnpm build
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/twin-model.test.mjs
```

生产部署由Sites负责。生产环境无外部应用权限、无数据连接器、无凭据。提供的浏览器WebMCP仅支持读取状态和导航业务视图，支持性依赖宿主浏览器；本次未完成受支持WebMCP环境验证。

## 瑞士主义视觉改版（2026-10）

以合欢红 `#E07563`、银白 `#F1F0EC`、石墨灰建立纸面风格；主标题48–88px，Oswald呈现英文与数字，Noto Serif SC 900用于中标题，Noto Sans SC用于正文。主场景占左侧宽幅网格，详情与事件位于右侧窄栏，资源及图层控制移至下方。弹窗、表格、趋势图、提示和三维模型统一使用低饱和配色。

全局 feTurbulence 灰度纸纹使用 `opacity: .08` 与 `mix-blend-mode: multiply`，覆盖层忽略指针事件。场景与重点面板使用 `0 25px 50px -12px rgb(39 37 34 / .25)` 阴影。保留所有业务计算与交互逻辑。
