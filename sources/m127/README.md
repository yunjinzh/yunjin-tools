# 山川人海 · Ridge Atlas

一个无构建依赖的高程 / 人口剖面线制图工具。页面在浏览器内运行，无需 API Key。

## 使用

1. 打开在线版本，或双击 `山川人海_本地工作台.html`。
2. 选择国家 / 中国省级行政区及下一级区划，或导入 WGS84 GeoJSON。
3. 勾选高程、人口或两者，设置人口年份和分辨率，点击“生成地图”。
4. 调整线密度、起伏、峰值、人口缩放和配色。支持高程图、人口图、叠加图和三联画。
5. “导出作品”可导出 2400 / 4000 / 6000 px PNG、SVG、主图采样 CSV、完整制图项目。

内置全部 23 个预设国家及中国 34 个省级行政区的真实 2020 年 / 1 km 人口与地形快照，默认“优先内置数据”，单文件版可断网生成、调图和导出。城市或自定义边界在快照覆盖范围内时可裁剪生成；小范围采样过少时改为联网读取。其他年份、100 m 产品或“实时读取”模式需要联网访问公开服务。在线读取有重试、超时和取消功能，失败会显示明确提示；仅在同为 2020 年 / 1 km 时回退到对应快照。保存的制图项目包含所用边界与已读取的栅格，可离线恢复。台湾下一级边界未由当前 DataV 源提供，可上传 GeoJSON。

单文件版使用 gzip 压缩数据，推荐使用支持 DecompressionStream 的新版 Chrome 或 Edge 打开。源产品的 1 km 分辨率与画布采样网格不同；大范围绘图会降采样，裁剪城市快照不会增加实际细节。

## 范围与坐标

- 内置中国 34 个省级行政区，含台湾、香港、澳门。全国主图显示纬度 18°N 以北的主体，南海诸岛在定位附图显示。台湾、香港和澳门另有独立数据放大图。
- 其他 22 个国家预设采用 Natural Earth 1:110m。美国预设为本土 48 州，法国预设为欧洲本土，均已明确标注。
- DataV 使用 GCJ-02；本工具作近似逆转换后与 WGS84 栅格配准，适用于概化数据艺术展示，不用于工程测量。台湾边界保持原经纬度。
- 用户 GeoJSON 默认 WGS84，经纬度坐标；也支持明确选择 GCJ-02。支持 Polygon、MultiPolygon、Feature、FeatureCollection、孔洞和多个要素。文件最大 12 MB，30 万个顶点。纬度限 ±85°，暂不支持跨越 180° 经线的单次范围。
- 中国全国范围将验证台湾、香港、澳门覆盖；自定义全国项目缺失必要区域时不以“中国”命名导出。该校验是基础防遗漏检查，不能代替边界合法性或完整性审查。

## 数值与视觉

横线是固定纬度剖面，不是等高线。地形高度单位米；人口为密度（人/km²），不是人口总数。两者独立归一化后叠绘，物理单位不相加。默认人口平方根缩放，以有效采样 P99.7 作视觉截断；真实原值保留在 CSV。高程以 P99.5 作视觉上限，负高程绘制在基线。公开 DEM 在局部地区可能有孤立异常值；页面展示 P1—P99 主体范围，CSV 保留原始采样值供复核。局部图独立归一化，峰高不可跨图直接比较。

地形在选定瓦片级别按最近像元采样；人口服务按视窗进行双线性重采样，再按线位置读取。高密度剖面和高清导出不会提高原始栅格空间分辨率。低分辨率全国视图可能遗漏小范围人口峰值。图形用于探索和设计，不计算精确人口合计。

TIFF 解析支持当前服务的无压缩 Float32 格式，显式处理空块及 NoData，缺测断线而非填零。若服务编码改变，会明确报错。读取超时 / 失败保留上一幅地图，不生成模拟数据。

## 数据来源与署名

核验及内置快照获取日期：2026-11-03。

- 高程：Mapzen Terrain Tiles，https://registry.opendata.aws/terrain-tiles/ 。不同地域使用不同底层高程数据，原始数据年份与许可见 https://github.com/tilezen/joerd/blob/master/docs/attribution.md 。Terrarium 解码：R×256+G+B/256−32768，单位米。
- 人口：WorldPop Population Density，Esri 托管年度 2000—2020 栅格。https://worldpop.arcgis.com/arcgis/rest/services/WorldPop_Population_Density_1km/ImageServer ，100m 服务同目录。WorldPop / CIESIN，CC BY 4.0，保留来源署名。该数据是人口模型估计，不代表实时人口。本工具使用这个经过实际调用验证的历史产品，并不声称它是 WorldPop 最新全部产品。
- 中国行政边界：阿里云 DataV GeoAtlas，https://datav.aliyun.com/portal/school/atlas/area_selector 。源的行政区划时效和概化精度应在正式制图前复核。
- 国际预设：Natural Earth 1:110m，https://www.naturalearthdata.com/about/terms-of-use/ ，公共领域。

## 开发与部署

`dist/index.html` 为在线入口；`core.js` 为数值和几何模块；`app.js` 为请求、制图与导出；`style.css` 为界面；`data/` 为真实数据快照及边界。静态目录可部署至 IIS、Nginx 或任意静态主机（需为 .json 配置 application/json）。无需 Node/Python 运行网页。

`scripts/build_local.py` 生成内嵌全部数据的单文件 HTML。`scripts/prepare_data.py` 用于重新获取快照，需要 Python、numpy、Pillow 及网络。行政边界快照另保存在 data/admin/，包含 33 个省级行政区的下一级边界。此版本没有提供通用全球县级区划接口。

实际验证：JS 语法；真实 WorldPop TIFF 解码与空块；多边形孔洞；浏览器加载全国快照、省市联动、北京在线读取、香港其他年份 / 100m 产品、GeoJSON 导入及导出下载。
