# 镜间造型室二维 Demo

基于《镜间造型室 人物装扮游戏设计文档 v0.1》制作的可玩样段。先验证画风、换装和作品创作流程；三维模型与真实环绕留待后续版本。

## 直接体验

下载单文件 HTML 后，使用 Chrome、Edge、Firefox 或 Safari 打开。程序、58 款矢量装扮和 5 个场景均已嵌入，不需要安装和外网资源。浏览器若限制本地文件持久化，页面会提示未保存，此时仍可换装和导出照片。

## 已实现

- 两位成年比例角色，同一目录不限制角色穿用；切换保留造型。
- 11 类、58 款二维装扮：发型 6、眉毛 4、眼睛 4、耳朵 4、嘴巴 4、首饰 6、项链 4、配饰 8、上衣 6、下衣 6、鞋子 6。
- 耳饰、腕饰、戒指、项链、头戴、眼镜、包与手持物独立槽位；6 档肤色与分部位预设颜色。
- 5 个原创二维背景：试衣室、地铁站台、植物温室、轨道观测舱、美术展厅。
- 全身、半身、特写取景；四种二维姿态；横幅和竖幅拍照。
- 三张公开条件主题邀约，不评判容貌或性别；未满足全部条件也能收片。
- 30 步撤销重做，分组随机，按槽位锁定；纯取景操作不占换装历史。
- 本机自动草稿、命名作品、重开编辑、另存、重命名和确认删除。
- 导出无操作界面的 PNG：竖幅 1080×1350、横幅 1920×1080。
- 桌面与窄屏布局、键盘操作、弹窗焦点管理、持久化失败反馈。

## 如何开始

1. 在衣橱点击分类与款式，即刻试穿；面容分类自动靠近，点锁定取景可以保持视图。
2. 打开“已穿与锁定”，固定喜欢的部件，再随机探索其余装扮。
3. 进入拍摄舞台，选择场景、姿态、取景和画幅。
4. 点击“拍下这一刻”下载照片；点击“保存造型”保留可重新编辑的作品。
5. 在作品册选择继续编辑。关闭页面再打开时，可选择恢复上一次草稿。

作品保存在当前浏览器和当前网页来源下，离线版与在线版不会自动同步；清理浏览器数据可能删除草稿与作品。照片另存到用户设备后独立保留。

## 范围边界

当前是二维矢量样段。58 个款号是已实现样段目录，不代表完成原需求的 220 款美术终验；5 个背景不代表 20 个三维舞台。二维轻侧身不是三维环绕，不支持背面观察、布料模拟、真实骨骼动画、账号云存档或多人。

## 源码与验证

`engine.js` 管理稳定款号、装备和存档，`avatar.js` 绘制人物，`scenes.js` 绘制背景，`app.js` 管理交互，`style.css` 管理响应式布局。运行 `python build.py` 输出 `dist/index.html` 单文件；运行 `node engine-check.cjs` 检查状态与存档逻辑。六维度走查和后续任务见 `UX_REVIEW.md`。

所有视觉为本项目原创矢量绘制，使用系统字体；没有外部图片、字体 CDN 或第三方埋点。
