# 语文探险岛

四年级上册互动语文练习。目前为第一至第四单元，16 个关卡、115 个任务。沿用浅绿色与米白色、小芽向导、地图闯关、探索值、星星、徽章和复习背包。

## 内容与界面

- `content/units/*.json`：每个单元一份独立题库，包含单元介绍、来源、关卡、题目、参考答案、提示、解析和可选教师说明。
- `src/`：共享界面与答题流程，不填写单元数量或题目总数。
- `scripts/build-content.cjs`：校验所有题库，自动生成单元目录、统计、带内容哈希的资源引用，以及在线、离线两种版本。
- `dist/`：生成结果；不要直接修改。
- `checks/game-check.cjs`：内容校验、奖励与复习流程、旧进度迁移、筛选、报告、未来单元接入的检查。

## 增加新单元

1. 在 `content/units/` 新增一个 JSON 文件，如 `05.json`。文件名只用于管理，展示顺序由正整数 `id` 决定。
2. 参考现有单元，填写 `id`、`label`、`title`、`heading`、`intro`、`icon`、`badge`、`source`、`summary`、`levels`、`questions`。`teacherNotes` 是可选的 `{label, body}` 数组。
3. 给新关卡和新题目分配永久唯一的 `id`，例如 `u5-1` 和 `u5-1-word-reading`。关卡的 `unit` 必须与单元编号一致；题目的 `level` 必须对应本单元已有的关卡。
4. 每个关卡至少一题，关卡数量不必为四。`color` 支持 `mint`、`peach`、`yellow`；`minutes` 是建议练习时长。
5. 执行以下命令，检查答案与讲解后再发布。

```sh
node scripts/build-content.cjs
node checks/game-check.cjs
```

新增单元会自动出现在单元入口、复习与记录筛选、徽章分组和学习记录中。题目数、关卡数、星星上限和网页说明均自动生成。单元入口自动换行，较多关卡会分行展示。

检查文件中的当前题库数量断言应在正式加入新内容后同步更新；其中的“第五单元”仅为内存中的扩展测试，不会写入真实题库或展示给学生。

## 题目格式

每题必填 `id`、`level`、`type`、`prompt`、`options`、`answer`、`hint`、`explain`。答案使用从 0 开始的选项下标：

- `choice`：单选，`answer` 是一个整数。
- `multi`：多选，`answer` 是下标数组，选择顺序不限。
- `order`：按顺序选词块，`answer` 是有序下标数组。若句子含重复词块，应给它们各自的选项位置，同一位置不能被选择两次。

可选 `word` 显示重点词或待补句子，`char` 高亮被考查的汉字，`context` 提供语境，`tag` 显示任务标签，`sourceRef` 记录与原练习的对应位置。新题应保留 `sourceRef`，便于核对。

## 保留既有进度

继续使用原来的 `yuwen-adventure-v1` 浏览器存储键。已经发布的单元、关卡、题目 ID 不要重新编号、删除或用于不同知识点。调整展示顺序不会改变历史记录。新增内容不清空探索值、星星、错题或徽章；已经获得的“全岛探索家”会保留。

“闷雷”读 mèn（第四声）；方以智原句为“善疑者，不疑人之所疑，而疑人之所不疑。”这两项用户确认的修正已保留，并列入检查。

## 离线与发布

`dist/offline.html` 是单文件离线版，内含样式、题库和交互，无联网依赖。若交付给老师，可另存为“语文探险岛-离线版.html”。浏览器进度不会跨设备、域名或文件位置同步，在线与离线通常各自保存。

网站沿用 `.openai/hosting.json` 中现有 Site 身份和私密访问设置。发布时同步源代码，并使用对应提交的 `.openai/hosting.json` 与完整 `dist/` 归档。每次构建自动更换发生变化的资源引用，避免旧题库缓存。
