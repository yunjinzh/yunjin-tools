# 楚河汉界 · 桌上兵事

中国象棋规则驱动的三维玩具军队观战应用。默认双 AI 对战，支持暂停、单步、悔棋、手动接管、镜头切换、种子复现和棋谱 JSON 导出。

## 严格分层

- `dist/engine.mjs`：纯逻辑棋盘、合法走法、自将过滤、飞将、将军/将死/困毙、和棋、走子/撤销和传统记谱。只依赖 JavaScript。
- `dist/ai.mjs`：有种子 PRNG、性格、四种开局、子力/位置/机动性/将帅安全评估、alpha-beta 2–3 层和 softmax。决策依赖棋局种子、局面与设置，不依赖墙钟时间。
- `dist/ai-worker.mjs`：独立 Worker，搜索每 160 节点主动让出时间片。设置变更或重开会终止旧 Worker。
- `dist/physics.mjs`：A* 避障路径、路径采样、按重力计算的抛体轨迹、反弹和摩擦。无棋局状态访问权。
- `dist/scene.mjs`：Three.js 棋桌、兵俑、战车/投石机、导播、攻击、退场、托盘、旗帜、呼吸和点击命中。只接受规则引擎已经确认的走法。
- `dist/canvas-renderer.mjs`：WebGL 不可用时，使用同一场景图的 Canvas 软件渲染；照明、遮挡精度与性能低于 WebGL 模式。
- `dist/app.mjs`：控制器。先由规则引擎提交走法，再启动演出；演出完成前锁定下一次走子。暂停冻结演出，后台搜索结果可以等待继续。悔棋从引擎历史重建场景。

## 规则范围

红方底部，9 × 10 交点。初始红方 44 个合法走法。将死、困毙均负。三次相同局面（含行棋方）、120 个半回合无吃子或累计 600 个半回合，判和。局面无合法走法的胜负优先于和棋计数。

这是明确约定的休闲规则，不实施专业比赛的长将、长捉责任裁定。显示胜率是浅层评估的 logistic 映射，不是校准后的统计胜率。

## 重放

同种子、同设置、同输入产生相同决策。每步记录设置，重放按钮恢复设置变化及已记录的人工走法；AI 着法重新推演。未走完的部分继续由 AI 决策。浏览器刷新不恢复会话；需要留存时使用棋谱导出。

## 运行与验证

无运行时 CDN、无后端、无重型物理库。Three.js 0.180.0 已本地打包并附 MIT 许可证。通过 HTTP 静态服务器打开 `dist/index.html`（ES modules / Worker 不支持直接双击 file://）。

```sh
npm test
node tests/acceptance.mjs
python3 -m http.server 8080 --directory dist
```

规则测试含三层 perft（44 / 1920 / 79666）、蹩马腿、塞象眼、不过河、九宫、炮架、兵卒、飞将、解将、困毙、将死、重复、无吃子计数、撤销、记谱、种子和抛体校验。验收脚本完成两盘不同种子对局，并检查同种子完整重放。

## 演出边界

自定义物理仅用于表现，不是通用刚体引擎。正常移动沿具有间隙的 A* 路径，马跳跃，拥挤无路时用抬高的跨越动作避免穿插。吃子后反弹倒地，化为花瓣退场并收集到托盘。模型为程序化玩具兵俑。

## 验证环境限制

当前自动化浏览器禁止 WebGL，已在 Canvas 兼容模式验证界面和手动落子；WebGL 阴影和光照尚未经该环境的像素级验证。
