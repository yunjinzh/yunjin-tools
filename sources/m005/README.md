# CIM 技术应用 · 能力图谱

课程教学原型，编制于2026-10-25。8能力域、32能力、128知识点、8任务、32证据、4岗位方向；213节点、390关系。

## 运行

直接打开 dist/index.html。该单文件无外部运行依赖；外部标准来源链接需联网。构建：python build.py；数据结构校验：node validate.cjs。

## 功能

图谱全景、模块下钻、局部关联网络、搜索、矩阵、前置依赖路径、任务评价、16题知识诊断、合成数据质量检查与空间分析。可导出HTML/JSON/CSV/SVG/任务单，打印当前页面；学习档案可导出、导入。学习状态和编辑只存当前浏览器。

## 来源与边界

教育部2025年专业教学标准与住房和城乡建设部CIM框架，以及OGC、buildingSMART、QGIS、GDAL官方资料。8领域、96学时及任务量规为课程设计，非国家统一教学大纲。用户指定微信文章未读取到正文，已在来源页明示，未宣称完成逐项映射。

## 验证

数据端点、知识—能力覆盖、能力—任务—证据覆盖、前置无环、学时总量与静态内嵌依赖已检查。浏览器检查了首页、模块下钻、搜索、学习状态、前置路径、任务页、测验反馈、质量门禁、实验参数、关联视图与390px窄屏布局。

合成数据实验：12条原始记录、3条异常、9条有效。R=150m覆盖3条，水位3m筛出4条；R=350m覆盖9条，水位0m筛出0条。
