# 视野 FIELDNOTES 产品走查

日期：2026-11-09。范围：发现案例、收藏、对比、案例详情三页签、导入、选题实验、创作模板、每周更新；桌面、390px 手机、768px 平板。

方法：任务走查、界面实测、源码审查与隔离数据测试。未进行真实目标用户访谈或量化可用性试验；以下是基于可复现行为的专家评估，不代表已经达到任何行业排名。

## 优先级
- P0：资料永久损失、越权或核心服务不可用；本轮未观察到已发生的 P0 事件。
- P1：可能丢失编辑、错误理解证据、关键任务中断；本轮优先修复。
- P2：影响重复任务效率、扩展性或进一步降低认知负担；形成可执行后续方案。

## 六维度发现

| 维度 | 原问题 | 等级 | 修复目标 |
| --- | --- | --- | --- |
| 信息架构 | 页面切换不反映在 URL，刷新回到起点；每周队列入口不真正筛选 | P1 | 导航可恢复，浏览器后退有效，核验入口直接定位待处理案例 |
| 用户流程 | 遮罩、关闭、Escape 可直接丢失编辑或实验；草稿缺少明确保存状态 | P1 | 脏数据提示、继续编辑/放弃选择、关闭后恢复焦点、保存状态可见 |
| 操作效率 | Ctrl 多选不适合手机；收藏/对比偏好消失；空状态只有重置 | P1 | 可触控关联选择、恢复对比和偏好、针对空状态提供下一步 |
| 反馈机制 | 错误也显示成功勾；加载/未登录仍可触发写入；冲突只靠客户端 | P1 | 错误、提示、成功分别表达，保存互斥，服务端一致性验证 |
| 视觉层级 | 大量 8–11px 低对比字；手机首屏被说明和统计占满；平板主区过窄 | P1 | 正文可读、控制目标可点击、首屏更早到达搜索和案例，按内容宽度布局 |
| 组件一致性 | 弹窗无统一焦点/背景滚动约束；筛选选中、状态色和动作反馈不统一 | P1 | 统一弹窗行为、焦点态、选中态、禁用态和移动端导航 |
| 研究可信度 | 检索日期与统计采集日期混淆；详情/表格都缩写数字；品牌演示未单独过滤 | P1 | 来源类型与时间限制可见，细节显示精确数值，支持排除品牌演示 |
| 数据完整性 | 备份仅导出，不能在站内恢复；部分字段只前端校验 | P1 | 校验后预览恢复范围，不静默覆盖现有记录；后端验证格式与证据 |

## 本轮验收记录

- 上表 P1 修复均已落实到代码，并完成发现、收藏、对比、实验、模板、每周更新六页及详情三页签的交互走查。
- 桌面验证：品牌演示过滤由 10 条变为 8 条；对比保留所选案例并显示精确数值；刷新后恢复页面与对比选择；待核查入口实际应用队列筛选；未登录写入提供明确登录入口。
- 编辑保护：关闭未保存编辑时显示继续编辑/放弃选择；抽屉编辑采用固定底部保存操作；空收藏、空模板有明确下一步。
- 响应式验证：390px 手机和 768px 平板通过真实浏览器嵌入视口检查，无页面横向溢出；手机高级筛选收起、长标题抽屉独立滚动、平板使用折叠导航。
- 自动化验证覆盖：记录格式与范围、日期及证据、备份预检、身份隔离、首次创建/并发更新冲突、损坏记录隔离及外部接口异常。
- 最终结果：TypeScript 检查、生产构建、`scripts/check-research.mjs` 隔离回归及 Git 空白检查通过；实验关联额外验证存在性和跨用户隔离。外部网络错误用模拟响应验证可恢复反馈，未宣称完成真实 YouTube API 联调。
- 验证边界：生产站受登录保护，本轮写入回归在隔离数据库执行；没有冒充用户登录，没有使用生产资料进行破坏性测试。正式账户的完整操作链仍需后续用户任务试验覆盖。

## 不可混淆的产品边界
- 播放/订阅比是发现线索，不代表留存或质量。
- 搜索索引的检索日期，不等于数值实际采集日期。
- 品牌案例可研究表达方式；发布方收益声明不能自动变成独立验证效果。
- 字幕辅助提取为规则提取草稿，不等于观看视频或核验真实完播。
- 当前没有后台自动更新；未来须先验证数据访问和写入，再启用计划任务。
