# 万象寰宇｜世界地图艺术宫

独立静态 Three.js 艺术馆。新项目，未修改北京地图展。

## 运行与发布

- 静态产物位于 `dist/`，不需要安装或构建。
- 开发预览可使用 `python3 -m http.server 4178 --directory dist`。
- 检查：`node --check dist/app.js && node test.mjs`。
- Sites 发布由主任务处理；`.openai/hosting.json` 保留已注册的私有项目 ID。

## 展览与交互

环形石材展厅、黄铜框架、中央玻璃穹顶、天窗、青铜天球雕塑、十个主题区、五十幅外墙挂画和五十幅立式独立展板。画框、地面编号、展签、画灯、休息凳均为实际三维构件。全部100件使用最终图库真实图像，画面按原图比例显示，包含竖幅和方幅。

- WASD / 方向键移动、Shift 加速；拖动转头，可选鼠标锁定。
- 碰撞覆盖外墙、展板、柱、休息凳、花盆与中心雕塑。
- 触屏方向键＋拖动视角，平面图点击传送。
- 轨道总览可拖动旋转、滚轮缩放，切回漫游恢复原视角。
- 策展导览100站，每站9秒；暂停/继续/上一幅/下一幅/结束。
- 作品点击鉴赏高清图、缩放/平移、上一幅/下一幅、收藏，关闭保持原来机位。
- 完整目录、编号/文字搜索、按展区/已看/未看/收藏筛选。
- 白昼/夜幕真实改变天空、环境光、日光和画灯。
- 高/均衡/流畅画质，距离分级纹理加载与旧纹理释放，静态材质几何批合并。
- WebGL失败切换完整二维目录。浏览器存储不可用时仍可临时收藏/浏览。

## 素材与依赖

`maps.json`含100件目录。每件包含384px缩略图、1024px三维纹理和原尺寸高清WebP，分别位于`assets/thumbs`、`assets/maps`、`assets/full`。初次进入不加载全部高清。高清仅在鉴赏时请求。来源数据由素材核验任务记录；公开manifest不含私有文件ID。

Three.js r170本地独立模块（vendor/three.module.js），MIT许可证见vendor/LICENSE.txt。无外部JS/CSS/CDN运行时依赖。收藏和已看保存在当前浏览器localStorage，没有遥测或外部数据提交。

所有地图均属艺术风格创作，不作为精确地理、导航或行政区划依据。

## 验证

`test.mjs`使用真实Three.js几何/射线与DOM渲染替身。16项检查通过，覆盖100资源、DOM ID、几何数量、比例、所有观画点碰撞安全、100条直接观画射线、边界/家具碰撞、导览、暂停漫游、总览视角恢复、昼夜灯光、高清不移动机位、缩放、搜索收藏、传送、按需高清与WebGL降级。

独立QA另外提供素材解码与行为检查。当前执行沙箱启动的HTTP服务无法跨工具连接，因此本地真实WebGL截图尚未完成；DOM替身验证不等价于真实浏览器视觉、触屏、多点触控或帧率验证。生产部署后应再使用可用云浏览器复验。已停止临时服务。

## 第二版：A/B 双馆 200 幅

- A馆第一辑 A001–A100，B馆第二辑 B001–B100。目录覆盖200幅，可按展馆、展区、已看和收藏筛选。
- 同时仅挂载当前馆100幅，切馆释放旧几何、材质和纹理；异步纹理回调以馆代次隔离，防止快速切馆串图。
- 顶部切馆；左侧上一/下一展区；平面图下方十个编号可直接抵达当前展区展位。
- 指南中可选当前馆100幅或两馆200幅导览，跨馆路线自动切馆。
- 保留旧A馆数字ID（1–100）和原localStorage键；B馆用独立字符串ID B001–B100，旧收藏不覆盖。
- 目录提供JSON收藏/进度导出和合并导入。线上与本地版本之间通过此备份手动同步，不宣称自动云同步。
- 数据入口支持 `window.MUSEUM_MAPS` / `window.__MUSEUM_MAPS__`；图像路径通过 `window.MUSEUM_ASSETS` 可映射为内嵌数据或Blob URL，供独立单HTML打包。
- 即使内嵌高清原像素，GPU纹理仍按384/1024最大边缩小；高清查看保持原像素。
- 此版自测22项通过（真实Three几何/射线＋DOM替身），新增B馆全部100射线、200资源、跨馆导览、旧收藏保留、备份合并等。真实浏览器视觉验证仍由独立QA执行并单独记录。


## 第四版：B馆真实布局重构

B馆不再使用环形坐标与轨道材质方案。现在是矩形双翼、折线展廊、挑空中庭、首层与6米高二层，各50幅展品，两座实际可行走的空中连桥。侧边电梯按钮明确上下层，B小地图展示当前真实楼层。地面、栏杆、展墙碰撞与相机高度一致；观看与导览自动选择正确楼层。A环廊与原200图片/永久ID保持原样。

配置将style与layout分离，已有ring与terraced布局注册，展集分页不再冒充物理楼层。完整扩馆、路由和验证说明见GALLERY_EXTENSION.md。自测33项通过，包括真实向下射线验桥面与0.5米网格连通性，不只统计几何数量。真实浏览器截图仍受预览网络隔离限制，未声称已完成视觉验收。
