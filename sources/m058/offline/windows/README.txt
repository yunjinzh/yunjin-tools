GeoPBF 三维场景生成器（Windows 离线包）
========================================

启动方法
--------
1. 解压整个压缩包，不要只打开压缩包内部文件。
2. 双击 GeoPBF.cmd。
3. 保持黑色启动窗口打开，浏览器会自动进入工具。
4. 使用完成后关闭启动窗口，或按 Ctrl+C 停止本地服务。

系统要求
--------
- Windows 10 或 Windows 11
- Chrome 110+ 或 Edge 110+
- 浏览器启用 WebGL / 硬件加速
- 建议内存 16 GB 以上；北京市等较大 PBF 建议 32 GB

说明
----
- 不需要安装 Node.js、Python、Java 或其他运行环境。
- PBF 在浏览器本地解析，不会上传到服务器。
- 解析城市级 PBF 时会扫描整个文件；选区不设面积硬上限，大范围会耗费更多时间和内存。
- 不联网时可以解析 PBF、生成平面场景并导出模型。
- 在线底图、真实高程和影像增强需要网络连接；服务不可用时自动回退。
- GLB 支持材质和可用影像纹理；FBX 输出网格和材质颜色。

常见问题
--------
1. 浏览器没有自动打开：复制启动窗口里的 http://127.0.0.1:端口/ 到浏览器。
2. 提示未启用 WebGL：在 Chrome/Edge 设置中启用“使用图形加速”，重启浏览器。
3. Windows 安全提示：GeoPBF.cmd 只调用系统自带 PowerShell，在本机 127.0.0.1 启动静态服务。
4. 场景过大或内存不足：缩小选区，关闭影像，或先用 osmium 裁剪 PBF。
