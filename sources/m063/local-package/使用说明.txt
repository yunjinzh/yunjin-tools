论文可视化解读生成器｜本地完整包
==================================

一、正确启动方式

1. 先把整个 ZIP 压缩包解压到同一个文件夹。
2. 双击“启动工具.cmd”。
3. 浏览器会自动打开工具页面。
4. 使用期间请保持黑色命令窗口打开；关闭窗口即可停止本机服务。

请不要只把 HTML 文件单独复制出来直接双击。模型厂商通常会拦截 file:// 网页的跨域请求，这正是“Failed to fetch”的原因。

二、数据与密钥说明

- PDF 文件在浏览器本机解析，不会上传给本机服务。
- 点击生成后，提取出的论文文字与您填写的 API Key 会经 127.0.0.1 本机服务发送给所选模型厂商。
- 本机服务只绑定当前电脑的 127.0.0.1，不对局域网或互联网开放。
- 本机服务不写入数据库、不保存 API Key、不记录论文正文。
- 模型厂商仍会收到论文文字，请按其隐私政策和单位的数据规范使用。

三、连接方式

- 本机转发（推荐）：解决 OpenAI、Claude、DeepSeek、通义千问的浏览器跨域问题。
- 浏览器直连：适用于明确支持 CORS 的接口或您自己的 OpenAI 兼容代理。
- 自定义兼容接口：请选择“浏览器直连”，并填写允许网页跨域访问的 Base URL。

四、常见问题

1. 提示“未检测到本机转发服务”
   请确认是通过“启动工具.cmd”打开，并保持启动窗口未关闭。

2. 提示 401 / 403
   通常是 API Key 无效、权限不足，或 Key 无权使用所选模型。

3. 提示 404
   请核对模型名称；模型名称会随厂商更新而变化。

4. 提示 429
   通常是请求过于频繁或账户额度不足。

5. Windows 提示 PowerShell 权限问题
   启动程序会优先使用 Python 3；若电脑没有 Python，才使用 PowerShell 备用方案。可安装 Python 3 后重新双击启动。

五、停止工具

关闭“论文可视化解读生成器”命令窗口即可。本机端口 8765 会随之释放。
