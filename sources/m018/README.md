# 知音工坊

知识歌曲创作工具：上传资料后自动识别主题候选，通过两阶段AI流程先理解和提炼思想，再完成歌词、编曲与演唱方案。

## 当前流程（2026-10-11 更新）

1. 在浏览器解析文字型 PDF、DOCX、PPTX、TXT、MD，保留原文来源。
2. 自动依据正文标题与高频词识别主题候选，不再要求填写歌曲主题。
3. AI分析全文：自动确定最终歌曲主题、一句话核心命题、核心观点、通俗解释、记忆句、叙事角度、意象、韵脚以及信息取舍。
4. AI根据上述提炼重新创作歌词：建立情境、精简短句、组织副歌，并给出观点与实际歌词片段的对应关系。
5. 检查多个长句照抄和观点映射缺失；触发时追加一次修订。修订后仍有问题的作品在页面明确提示。
6. 逐项展示“原文依据 → 通俗提炼 → 歌词表达”，保留来源引用核对及可编辑输出。

已移除将原句拼接成歌的本地生成入口。没有API Key时仍可识别主题候选，并复制完整两阶段指令到已有AI软件；导回包含analysis字段的JSON后，使用同一套核对与导出功能。预置数字孪生示例是提前创作的内容加工演示，界面明确标为“预置加工示例”，不宣称是联网实时生成。

## 能力与边界

- 24种音乐风格、9种演唱方式；提供独立8小节旋律草案试听和MIDI导出。
- TXT创作包包含主题、观点、记忆表达、歌词加工对照、歌词、编曲与依据；JSON保留工程及提炼结果。
- 本浏览器收藏最多20份，可恢复旧版工程；旧版草稿保留原标识。
- 不含OCR。单文件20MB、PDF100页、项目80,000字。
- 完整语义提炼和原创改写需要用户自己的DeepSeek或阿里云百炼（北京）API Key，或通过外部AI往返。
- 标准流程调用模型两次，触发质量修订时额外一次。每阶段超时110秒；费用计入用户API账户。
- 原文引文必须在相应来源中逐字匹配。照抄检查与片段映射是文本规则，不等于语义正确性保证。
- 不自动提交第三方音乐平台任务。完整人声成曲由音乐平台生成。
- 密钥仅驻留页面内存，调用时经本站服务端发送到固定官方API；不写入收藏、工程或应用日志。
