# 梁山小英雄 · 108人物奇遇记

儿童互动水浒人物游戏。九张原创角色图、108则人物小传、九个营寨。

## 功能

- 看图识人：每组12题，四选一，线索与即时小传。
- 绰号配对：每组两轮，每轮六对，配对完成点亮人物。
- 本领挑战：根据小传辨认人物。
- 收藏图鉴：108人物搜索、分组、已认识与待复习筛选。
- 自由选关、星星纪录、连击奖励、七项成就、错题复习。
- 本地进度保存、JSON进度导入导出、可选音效与设备语音朗读。
- 手机与桌面响应式布局，键盘1-4答题，对话框焦点约束，减少动态效果支持。

## 实现

buildless HTML/CSS/JavaScript；无CDN、外部字体、账号或服务端依赖。
角色插图通过CSS背景定位复用九张原图。线上资源分文件加载。
运行 `python3 build-offline.py` 可生成图片内嵌的单文件离线HTML。

## 检查

`node --test tests/engine.test.cjs`
`node --check dist/app.js`

姓名、绰号、座次和人物小传复用本系列已核对的《水浒传108人物传·Q版儿童图鉴》。
说明：浏览器语音是否可用取决于设备；文件协议下存储受浏览器设置影响，可导出存档备份。
