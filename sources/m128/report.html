公开资料调研与复现方案

调研日期：2026-11-07 · 目标：可操作、可拆解、可演示的 HTML 教学工具 · 适用：中学拓展、大学地学导论与教师演示

结论：采用“公开运动学模型重建 + 浏览器交互展示 + 独立机制教学”的组合路线。本交付已经内置 250–0 Ma 的真实重建切片；不以手绘大陆轨迹替代科学模型，也不声称完成地幔动力学求解。

一、究竟要复现什么

板块演化至少有三个不同层次：大陆及地质体的位置变化，板块边界和拓扑关系的变化，以及板块运动背后的物理机制。第一层需要几何体和旋转模型；第二层还需要按地质时间解析的边界；第三层涉及温度、密度、黏度、应力与流变等条件。只移动几块大陆图片无法表达海洋板块生成、消减和板块重组。

因此本工具将“科学重建”与“概念机制”分开：主视图回答“模型在这个时间把板块重建在哪里”；剖面动画回答“不同边界可发生什么”。这两个问题不能用同一个动画的逼真程度互相证明。

三、科学依据与不确定性

现代观测可利用卫星测量约束当代运动；地质时期的重建需综合古地磁、海底磁异常、地层与造山带对应、热点轨迹等证据。不同证据在不同年代的可用程度不同。古海洋岩石圈会被俯冲消耗，深时海盆恢复尤其依赖模型假设。

模型中的经纬度是在其所选参考系中的重建位置。古地磁对古纬度的约束通常强于古经度；绝对参考系选择会影响全球位置和运动。不能把现代运动速度直接线性外推几亿年，也不能把一种模型的结果描述为唯一答案。

本页“大陆轮廓”是用于辨认陆块的重建轮廓，并非完整古海岸线。海平面、侵蚀、沉积及地表形变均可改变海陆分布。地球上的政治边界不适用于古地理切片，因此本工具不绘制国家行政边界。

关键资料限制：[!!! 事实断层：资料不足，无法确认] 公共接口没有在本次返回中提供每个顶点的不确定性区间，也没有返回底层模型文件的精确提交号。因此不输出“误差 ±若干千米”或虚构精度等级。已保存接口参数、获取日期和响应文件 SHA-256，确保本次数据快照可追溯。

五、数据流程和可拆解的工程结构

源数据 → 预计算/下载 → 校验与显示抽稀 → 离线 HTML → 交互与导出。本次调用三种接口：/reconstruct/coastlines/、/topology/plate_polygons/、/topology/plate_boundaries/，全部显式设置 model=MULLER2019 和时间。共 78 个有效 FeatureCollection，覆盖 26 个时刻的三类图层。未使用默认模型，避免服务默认值变化造成混用。

下载脚本负责获取原始响应；构建脚本记录文件哈希和时间清单，再将数据与 D3 依赖嵌入 HTML。显示抽稀保留折线首末点及跨日期变更线附近跳变，采用经纬度距离阈值；这种简化不是拓扑保持算法，因此不作为边界长度、板块面积或相邻关系精算依据。浏览器端调整球面环绕方向仅为兼容渲染约定。

工程分成数据模块、时间状态模块、地图渲染模块、教学剖面模块和输出模块。可以独立替换其中一层：例如将静态数据换为自建服务，不需要重写课堂任务；将 Canvas 渲染换为 Three.js，不需要改变时间和模型标识。

六、为什么本版采用此技术路线

课堂需要可重复启动、便于下载和不依赖 GPU 的稳定展示，因此选用原生 HTML / JavaScript、Canvas 与 D3 地理投影。对于“观察重建地球、拆分板块、切换年代”已经足够；增加 WebGL 材质并不能提高模型真实性。

若下一阶段需要真正的三维壳层、板片深部几何和多人实训，可采用 Three.js；若需要发布到学校 IIS，可直接部署本版静态 HTML。研究级连续重建则应在服务端使用 pyGPlates 解析旋转模型与动态拓扑，再向前端输出经过版本管理的结果。不要对拓扑不同的两个多边形做简单顶点线性插值，否则可能出现跨洋拉伸、交叉和虚假的板块身份延续。

七、复现与验收建议

  • 启动：直接打开单文件 HTML；核心数据与脚本均内置。来源链接仅在点击后联网。手机文件预览器若禁用脚本，使用已发布网页或完整浏览器。
  • 操作：先从 250 Ma 播放至现代；再暂停并选择板块。分离观察结束后复位，再分析地理位置。演示模式可用 Esc 退出，也可点击退出按钮。
  • 内容：对照 GPlates 同模型、同时间、同参考系视图核验。不要拿不同版本截图的差异直接判为程序错误。
  • 工程：检查所有 78 个响应均可解析，26 个时间都有完整图层，所有坐标为有限数；导出文件应保留模型、时间和许可。
  • 教学：学生应能解释大陆与板块的区别，辨认四种机制，指出模型的不确定性；不能只考查会不会按播放按钮。

八、分期扩展与成本驱动因素

第一阶段即本交付，完成公开数据驱动的离线演示。第二阶段可将采样改为 1 Ma，并增加固定参考点、相对位移、区域专题和模型对照；这会增加数据体积与模型核验工作。第三阶段可加入深时模型、真实地球内部结构数据、地震震源和火山数据，但每层需单独定义年代、来源与许可，不能把现代地震点机械地贴到远古地球上。

真正影响工作量的是模型范围、数据整理与跨时拓扑、速度和形变精度、终端性能、教学内容审校，而非仅仅“制作一个转动的地球”。本次未获得班级规模、目标课程标准和学校终端配置，因此未给出虚构的并发指标、合同工期或报价。
