# 共境具身智能实训平台

版本 0.1.0，编制日期 2026-10-21。

依据用户提供的《具身智能机器人虚实融合训练场_PRD_V1.0(1).docx》（2026-10-21）开发的可运行前端原型。平台服务于学生实训、校内自定义竞赛流程和教师初步算法验证。

## 运行与部署

静态入口为 `dist/index.html`，不需要后端服务和外部 CDN。Three.js 0.180.0 和 OrbitControls 已随资源交付。请通过 HTTP/HTTPS 静态服务访问；ES Modules 不支持直接双击本地 HTML 作为完整运行方式。

本地运行：安装 Python 3 后，双击部署包中的 `start-windows.bat`，或执行 `python start-server.py`。访问 `http://127.0.0.1:8088`。启动器默认只绑定本机。

IIS/Nginx 部署：将 `dist/` 内文件保持目录结构复制到站点或子目录，设置 `index.html` 为默认文档，并确保 `.js` 按 JavaScript MIME 类型提供。静态文件不包含访问控制；如需校内访问限制，应由学校的 Web 服务实现。

开发验证：`npm ci`，然后 `npm test`。运行不需要 npm，仅开发验证需要。

## 首次体验

1. 打开实训工作台，点击“开始仿真”，观察咖啡任务的七个技能与路径。
2. 切换物流搬运，将箱体配送至 B-01、B-02 或 B-03。
3. 点击“编排任务”，调整技能顺序或增加回位；错误顺序会被校验器拒绝。
4. 尝试“给张老师送咖啡”，系统提示缺少交付点；改用“把咖啡送到沙发交付点”生成任务。
5. 运行结束进入“数据与回放”，查看二维轨迹、三维复盘、技能事件和评分，导出 JSON/CSV/实验简报。
6. “教学与课程”包含八个实验。顶部体验身份切换为教师后可发布本地教学任务；学生可提交关联运行证据的报告。
7. “竞赛中心”支持配置并冻结赛题。参赛记录携带规则快照，裁判复核保留原始评分。
8. “技术验证”按相同种子生成环境，比较 A* 与直线路径基线。实测轨迹由用户提供并核对任务、单位和时间基准后导入。

## 数据

数据保存在当前浏览器 localStorage，最近 50 次任务保留完整参数、轨迹和事件。重要记录请主动导出。实验报告正文和参赛显示名也保存在本地，外部清理浏览器数据后不可恢复。

运行记录 JSON 的 `mode` 为 `kinematic-simulation`。实测对照明确标注 `user-provided-unverified-telemetry`。不会预置虚构学生成绩或设备在线数据。

轨迹采样包含 `t, x, z, yaw, step, carried, placed`；时间按仿真步进累计，不是物理设备时间。真实轨迹输入仅要求 `t, x, z`，t 非负严格递增，单位为秒，XZ 为统一坐标系内的米。误差计算基于重叠区间及仿真轨迹线性插值。

## 评分

默认教学示例权重为完成度 50、安全检查 30、效率 20，时间基线 90s。此为原型设计，不是 PRD 确认的官方分值。

- 完成度 = 权重 × 已完成技能数 / 总技能数。
- 安全检查 = 未触发运动碰撞检查时获得该项权重，触发则为 0。
- 效率 = 成功任务的权重 × max(0, 1 − 仿真耗时 / 时限)，未成功时为 0。
- 软件急停使总分为 0。竞赛到达时限会停止并记录 TIMEOUT。
- 人工复核单独记录，不覆盖自动分。

## 验证范围

已通过 11 项引擎测试和 8 项 DOM 操作集成测试，包含六个交付目标、障碍规避、急停锁定、任务依赖、指令消歧、确定性评分、配对实验、轨迹插值、赛题冻结、报告关联与回放入口。

当前制作环境没有支持的浏览器验收工具，尚未进行真实浏览器 WebGL 画面、布局、鼠标操作、下载、语音权限与多终端兼容性实测。DOM 集成测试使用非浏览器 DOM 环境和二维降级视图，不应视为浏览器视觉验收。

## 接入实机前必须明确的项目输入

机器人品牌型号、SDK、载荷曲线、末端夹具、关节接口、厂商安全状态、物理急停和场地测量尚未提供。现阶段无法确认实际搬运重量、夹持稳定性或热饮操作能力。三维示例中的动作不能用作设备性能承诺。

## 文件与实现

- `dist/engine.js`：确定性规划、任务状态机、评分、批量实验、轨迹误差。
- `dist/scene.js`：Three.js 场景、程序化模型、视角、选择、路径、回放姿态。
- `dist/app.js`：页面、教学、竞赛、导出、数据管理。
- `dist/style.css`：响应式界面。
- `tests/`：引擎与 DOM 操作集成测试。
