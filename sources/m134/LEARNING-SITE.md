# 地图研习社 · MAP ATELIER

独立学习站，保留热门精选、收藏、学习进度与笔记。不包含选题策划、脚本模板、频道规模比较和创作实验。

## 内容规则

- 首批 12 条 YouTube 原始视频，同时满足单条播放量 ≥100,000、点赞量 ≥1,000。
- 来源证据存于 CONTENT-SOURCES.json；前端目录 app/lib/catalog.ts。更新时同时更新两处，不将未知指标填为 0 或编造时长。
- 2026-11-09 是检索日期，不是统计真实采集时间。全部指标为公开搜索索引快照，点赞可能取整，非实时排名。
- 中文导读基于作者公开标题与说明。仅在作者明确提供章节时收录时间入口。
- 地图动画、制图实操、三维地形、设计原理、手绘地图五类。虚构地图、赞助内容和旧软件版本在详情中说明。

## 保存与验证

- D1 保存每位登录用户的收藏、进度和笔记。页面本身不缓存账号资料到浏览器存储。
- 笔记最多 10,000 字符；关闭及离开保护；并发修改采用版本号检查。未登录不能写入。
- 原视频在用户点击后才加载嵌入播放器；始终提供原始链接。缩略图直接来自 YouTube，有加载失败后备图。
- `node scripts/check-learning.mjs` 在隔离 D1 上验证收录双门槛、来源ID、鉴权、跨用户隔离、笔记保存和重读、并发冲突、非法内容。
- 真实浏览器验证：搜索QGIS并叠加1万点赞筛选命中1条；原始数值详情；关闭笔记提示；继续编辑保留原文；收藏与笔记空状态；390px手机和768px平板；手机正文和弹窗无横向溢出。
- 生产登录后的用户写入未用真实账号执行；后端在隔离数据中完成测试。YouTube嵌入能否播放受访问环境与作者设置影响。

## 维护入口

更新目录后使用既有 project_id 发布。保持该独立站点与原“视野 FIELDNOTES”研究站的数据、身份与源码分离。

## 核心内容更新（2026-11-09）

12条视频均补充一句话理解与3–4个具体核心点，提炼来源单独记录于 CORE-CONTENT-SOURCES.json，前端为 app/lib/core-content.ts。6条使用公开字幕转录或片段，1条使用原页面章节，5条使用作者说明/作者补充资料/作者置顶评论。所有来源层级明确标注，未宣称完整逐帧验证。纽约地铁图条目将2025年官方现状单列为时效补充。后续维护约定见 UPDATE-GUIDE.md。
