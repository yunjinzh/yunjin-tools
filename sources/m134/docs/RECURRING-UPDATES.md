## 无人值守读写路径

1. 通过 Sites `get_site` 读取该站，确认仍为原账号 owner-private。使用返回的 `siwc_bypass_bearer_token` 仅访问本站，放入 `OAI-Sites-Authorization: Bearer …` 请求头。它不代表学习者身份，不能用于写用户笔记。
2. 源码中的 `scripts/catalog-service.py` 通过隐藏 stdin 接收 JSON。`action:get` 会 GET `/api/catalog`；`output` 可指定本次临时工作文件。不要把 token 写入文件、命令行、输出或任务提示词。
3. 读取的对象包含 `revision`、`updatedAt`、`message`、`lessons`、`coreContent`。基于完整现有对象合并，保留所有已有 ID。构造发布 JSON：`{baseRevision,requestId,payload:{lessons,coreContent},message}`。requestId 是本次运行唯一的 8–100 位字母数字/下划线/短横线；重试复用。message 简述新增、核验或未找到合格新内容的结果，不能虚报核验完成。
4. `action:publish,input:<本次JSON路径>` 调用 POST `/api/catalog`。服务端校验双门槛、原视频链接、核心内容、ID 保留与 baseRevision，再以 CAS 写 D1。此步骤只改资料，不发布网站、不改个人记录。
5. 再 GET 并对比 revision、各新增 ID 及源链接。网络结果不明确时先读回；若当前 requestId 已写入，再次提交会返回同一结果。409 必须重新读取合并，不能强制覆盖。
6. 每轮报告成功更新数、无法核验的内容和实际阻塞。没有证据不要改旧内容；通道不可用时不声称更新成功。无需等待网页打开，用户下次联网时页面自动下载资料。

## 离线使用

首次联网登录，等待“离线资料已就绪”，再从页面“安装离线版”或浏览器菜单安装。缓存包括应用外壳和打包资源；资料保存于 IndexedDB；已登录账号的学习记录以账号 ID 隔离保存。断网时仍可打开、搜索、阅读核心内容和保存学习记录。第三方视频需联网，尚未下载的封面可用占位图。

网页启动、恢复联网、回到前台时检查资料，打开期间每 30 分钟检查。资料更新不会自动刷新页面；详情打开时推迟替换内容。应用代码升级采用 Service Worker 等待机制，关闭所有站点窗口后生效，避免清掉未保存输入。

本机记录在保存后进入待同步队列。恢复联网时确认当前账号，并在详情关闭时同步；版本冲突保留草稿由用户选择。浏览器拒绝存储时明确报错。清除站点数据会清除未同步记录，建议导出备份。不能保证被浏览器清理或私密模式关闭后的离线副本仍存在。
