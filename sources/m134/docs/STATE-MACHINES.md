# 地图研习社：状态机审计与维护契约

范围：当前地图设计学习站的 `app/`、`db/` 和运行时交互。框架、浏览器和身份平台内部状态不重写，只记录本站依赖的边界。精选视频、来源与核心内容未改动，数据库结构不变。原始基线提交：`19c3ff265bfa0eaa84325ea18269f2a792b88543`。

## 决策

把相互影响的领域状态集中到带类型的纯 reducer，把请求、计时器和浏览器历史放在薄适配层。保留 React、原生 dialog/details 和已有数据库的乐观并发控制，不引入新的状态管理依赖。清洁/未保存、结果是否为空、收藏数等由事实推导，不再各存一份易失同步的布尔值。

## 全量清单

| 状态机 | 状态与触发 | 决策、边界与可观察信号 |
| --- | --- | --- |
| 页面导航与历史 | 精选 / 收藏 / 笔记；切换、返回、前进、刷新 | `catalogReducer` 统一切换。每个历史条目保留筛选；切换栏目回默认筛选。详情草稿不因背景历史变化丢弃。`data-view`、`aria-current`。 |
| 筛选与排序 | 查询、主题、双热度门槛、进度、排序；修改、重置 | 同一状态对象；URL 编解码校验枚举和数值。结果、空态由筛选函数推导。`role=status` 报告条数。 |
| 记录读取 | loading(request) → ready / error；重试 | 请求 ID 拒绝过期响应；20 秒请求超时；读取失败与空数据分开。保存中不启动覆盖性读取。`data-read-state`。 |
| 身份 | 未知 / 已登录 / 匿名；读取确认、写入 401 | 身份只来自服务端响应；401 保留草稿并转匿名。个人页明确提示登录，不显示虚假的“尚无收藏”。`data-auth-state`。 |
| 详情与说明弹窗 | closed / method / lesson(editing, confirm-discard) | 单一判别联合，两个弹窗不能并存。脏草稿关闭需确认；确认中 Escape 继续编辑；保存中关闭被守卫。`dialog[data-state]`。 |
| 焦点与滚动 | 页面触发器 → 原生模态 → 确认 → 编辑 / 页面 | 原生 dialog 管理焦点范围、背景 inert；确认层使编辑区 inert；关闭回原触发器，新开滚动到顶部。 |
| 编辑草稿 | baseline + draft → clean / dirty | 显式比较可编辑字段；revision/updated 不制造假脏。保存期间继续输入，响应仅推进基线和版本，保留后来输入及撤回操作。`data-dirty`。 |
| 写入请求 | idle / saving(request,snapshot) / error / conflict | 同步 dispatch 镜像防同帧重复提交；请求 ID 防旧响应；超时属于结果未知，保留输入；重试仍提交原版本，服务端 CAS 防覆盖。`data-save-state`、按钮 disabled、状态文案。 |
| 多设备冲突 | 409 → 对照云端 → 保留草稿或采用云端 → 显式保存 | 409 返回同一账号该视频的最新公开字段，不含 owner/key；不自动覆盖云端。草稿可先下载。保留草稿会更新基线，再次点击保存才写入；若再次冲突，继续对照。 |
| 收藏 | 未收藏 / 收藏；卡片立即提交、详情修改草稿 | 保持现有操作差异，全部走同一保存门禁。详情使用“已选收藏”标识未提交意图；卡片保存途中打开详情时，合并未触碰字段。 |
| 学习进度 | 未开始 / 学习中 / 已学完 | 用户可手动前后调整，和播放器状态独立；不把 iframe 加载当作学完。状态随草稿显式保存。 |
| 视频嵌入 | poster → loading(attempt) → embedded / unavailable；重试 | 15 秒未完成框架加载提供重试；事件同时匹配视频 ID 与 attempt。embedded 只表示 iframe 打开，不代表视频可播或播放完成。始终保留原始链接。 |
| 封面 | 原图 / 失败占位 | 失败按视频 ID 记录，换视频不继承其他视频的错误。保持轻量局部状态。 |
| 通知 | hidden / visible(id) → timeout / dismiss | 只按通知 ID 清除，旧计时器不能关闭新消息；详情内通知进入原生 dialog 顶层，确认时 inert。失败同时保留内联恢复信息。 |
| 下载与来源披露 | 无笔记 / 可导出；文件生成并请求下载；来源收起 / 展开 | 导出仅在记录已读取且有内容时可用；另支持当前草稿下载。提示只声称“生成文件”，不声称浏览器已落盘。来源披露继续用原生 details，不复制 open 状态。 |

## 修复优先级与取舍

- P1：保存回执覆盖新输入；并发冲突只能刷新、容易丢笔记；初始读取晚到覆盖编辑基线。已修复并覆盖回归场景。
- P1：详情弹窗顶层阻挡外部错误提示，保存失败反馈不可达。通知已移入当前模态层。
- P2：读取失败、匿名、空收藏混淆；返回/刷新丢筛选；过期请求与播放器事件串扰；封面失败串到其他内容。已修复。
- 保留：卡片收藏即时提交、详情集中保存、手动标记学完、来源折叠、现有视觉层级。
- 暂不加入：自动保存、离线同步、跨标签页实时广播和独立 Agent 写接口。这些会改变写入语义或增加认证与冲突面；当前统一事件与可观察状态足以让用户、维护者和浏览器 Agent 走同一流程。

## 代码入口

- `app/lib/learning-machine.ts`：读/身份、面板、草稿、写入、冲突、播放器、通知的事件与纯转换。
- `app/lib/use-learning.ts`：HTTP、超时、请求取消和通知时钟。未经 reducer 接受的写入不会发出。
- `app/lib/catalog-state.ts`：筛选状态、URL 编解码和导航转换。
- `app/lib/use-catalog.ts`：history 适配；筛选替换当前条目，栏目导航添加条目。
- `app/page.tsx`：由显式状态推导 UI，DOM 属性提供稳定观察点。
- `app/api/learning/route.ts`：账号隔离、参数校验、revision compare-and-set、409 最新记录。

## Agent 操作契约

1. 使用中文可访问名称寻找输入和按钮，视频用 `data-lesson-id` 识别；不要用卡片位置当 ID。
2. 只有 `data-read-state=ready` 才把个人记录视为已读取。`data-auth-state=anonymous` 不能写；按钮可点击不代表已经保存。
3. 编辑后观察 `dialog[data-dirty=true]`；提交后等待 `data-save-state` 离开 saving。dirty 仍为 true 表示提交之后又有修改，不应自动关闭。
4. conflict 是需用户选择的恢复分支；不得自动选“保留草稿”覆盖云端。error 是失败或结果未知，不应报告成功。
5. 关闭未保存详情应使用可见确认流程。不要借导航、刷新或 DOM 赋值绕过。
6. iframe 的 embedded 与导出的“文件已生成”都不代表下游完成。

## 验证

- `node scripts/check-state-machines.mjs`：23 个场景，覆盖加载乱序、重复提交、输入与撤回竞态、卡片/详情交叉、版本冲突两种恢复、401、失败重试、弹窗守卫、播放器代次、通知代次及 URL 往返。
- `node scripts/check-learning.mjs`：独立临时 D1 验证 12 条内容与来源、匿名读取、401、403、跨账号隔离、读写往返、并发 CAS、409 返回最新记录但不泄露内部字段、无效输入。
- TypeScript 类型检查与生产构建。
- 浏览器：搜索排序、导航返回、刷新恢复、详情核心内容、匿名保存反馈、草稿保留、关闭确认/Escape/放弃和焦点返回；390 px 手机和 768 px 平板 iframe 视口；手机详情实测 clientWidth = scrollWidth = 371，页面 clientWidth = scrollWidth = 388，无横向溢出；手机隐藏文字的“收录与更新”按钮补充可访问名称。

限制：私有生产站仍依赖真实账号登录；未操作用户真实收藏或笔记。认证写入与并发路径在隔离数据库测试，不能替代所有设备和第三方播放器环境的端到端测试。草稿保存在当前页面内存，主动放弃/关闭标签页会丢失未保存内容；离页提醒和草稿下载降低风险，不宣称持久化自动草稿。
