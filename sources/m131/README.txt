西游织梦 · 三维角色艺术馆

内容：114 位西游记针织羊毛角色，7 间连续室内展厅。

本地启动：解压完整压缩包后，Windows 双击 Start_Windows.bat（需已安装 Python 3）。
macOS / Linux 在本目录运行 python3 start_server.py。启动器只监听本机，浏览器自动打开页面。
请保持启动窗口打开。关闭窗口或按 Ctrl+C 停止。
也可把 dist 目录上传到任意静态网页服务器（IIS / Nginx 等）。
请勿直接双击 index.html：浏览器对本地文件的模块、纹理读取有限制，需通过本地 HTTP 地址访问。
网页、展览图片与 Three.js 均在包内，观展无需外网；“阅读原著篇章”链接需要联网。

操作：
- WASD 或方向键移动；拖动转头；滚轮前后移动；Shift 加速。
- 点击画作打开角色故事、身份、能力和人物关系。
- 角色介绍中的“定位展位”返回对应画作前；“放大看纹理”支持 1—5 倍缩放。
- 顶部“全部作品”可搜索角色、篇章、故事关键词及按角色类别筛选。
- 下方七个展厅按钮或展厅地图可快速跳转；“作品导览”按展位顺序浏览。
- ◐ 切换日夜；⛶ 全屏；触屏设备可用方向按钮移动并拖动画面转头。

画面：优先使用 WebGL；不支持 WebGL 时自动使用 CSS 三维兼容模式。
兼容模式保留空间、画框和互动，植物及灯光质感较为简化。
页面记录浏览过的角色数量，仅保存在当前浏览器本机。

图片：展览使用 WebP 副本；原始 PNG 在“西游记针织角色”四个独立压缩包中。
原图包分别覆盖 001—029、030—058、059—086、087—114，无需合并，分别解压即可。
角色编号固定；展厅次序按主题策展，因此导览序号与角色编号可能不同。
蜘蛛精姐妹的编号称呼为展览识别标签；原著没有逐一给出姓名。
人物故事依据《西游记》原著整理，视觉形象为针织玩偶艺术演绎。
