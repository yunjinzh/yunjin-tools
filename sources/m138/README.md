# 厂房空间复原

依据用户提供的 3 张室内照片及 9.6 秒视频制作的 Three.js 交互式空间展示。所有资源随站点提供，无运行时 CDN 依赖。

## 操作

- 鼠标左键拖动：观察；右键拖动：平移；滚轮：向前/后移动。
- 自由漫游：鼠标观察，WASD 或方向键移动，Shift 加速，Esc 释放鼠标。
- 双击可行走地面 / 点击右下角平面示意图：切换位置。
- 5 个预设观察视角、自动导览、屋面/墙体/设施图层、亮度与速度调节。
- 实拍对照：3 张原始照片与原始视频，可放大原图。
- 空间观察点：在设置中开启，点击查看影像依据与不确定性。
- 保存画面：下载当前三维画面的 PNG。
- 手机：拖动观察，屏幕方向键移动。

## 几何依据与边界

可辨认的构件类型：连续柱列、纵向深色钢梁、灰色主屋架、黄色檩条和交叉支撑、采光带、工矿灯、双层高窗、检修走道和爬梯、地面排水沟。可见设施包括西侧风电实训围栏和白色壳体设备、后部工作台和柜体、东侧实训设备及视频中出现的双层平台、入口展板。

没有平面图和实测尺寸，建模工作尺度设为约 36 × 42、屋脊高度 12.85 个场景单位。这些只是比例工作参数，不是实测米制结果。柱网总跨数、窗数、平台与设备精确位置、建筑背面及遮挡区域均存在估算，不能声称与现场逐项精确一致。没有生成机械设备内部结构或不可见细节。

照片与视频用于视觉关系参考，不属于可直接恢复精确三维的完整摄影测量数据集。此交付是人工参数化近似重建，不是 3DGS / 点云测量成果。

## 文件

- `dist/index.html`：页面。
- `dist/scene.js`：建筑、设施、材质、光照、几何批处理。
- `dist/app.js`：相机、导航、碰撞、图层、对照与导出。
- `dist/style.css`：响应式界面。
- `dist/assets/`：本地 Three.js、授权、用户影像。
- `.openai/hosting.json`：静态托管配置。
