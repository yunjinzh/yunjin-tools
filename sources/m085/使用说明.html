升级（保留旧队列）

1. 暂停正在运行的队列。
2. 将新版 extension 文件夹内容覆盖到原扩展的 extension 文件夹，保持原路径。
3. 在 chrome://extensions 或 edge://extensions 点击原扩展的重新加载，版本显示1.2.0。
4. 刷新即梦网页，重新打开扩展工作台，连接原音乐生成对话。
5. 原五首队列可继续检查和完成；下一次创建新批次时，默认抽取10种。

第一次使用

解压安装包到固定文件夹。在 Chrome/Edge 的扩展管理页面开启开发者模式，加载 extension 文件夹。
刷新已登录的即梦页面，点击浏览器扩展图标打开工作台，选择即梦标签页并连接。
在即梦选择音乐生成模式。填写主题，选择抽样范围、语种、演唱设定，点击“随机生成10组提示词”。
查看或编辑每组提示词，按需取消勾选；点击“开始创作并下载”后才提交到即梦。
程序生成的每条音乐使用平台账户额度。抽取提示词与浏览目录在本地完成。

随机抽取

- 默认：从全部526种类型随机抽取10种，同批不重复。
- 分类优先：选定分类有10种以上时，从该类抽取10种。
- 小分类：例如“中国戏曲与民歌”有7种，全部纳入，再从其他分类随机补足3种；页面明确显示补足数量。
- 每个新批次重新抽样。不同批次允许再次抽中某一类型。
- 已提交的任务保留原提示词；新批次不会覆盖尚未处理的生成/下载任务。
- “风格资料库”中的“优先从该分类抽取”用于设置创作范围；搜索框和类型维度用于浏览目录。

队列与下载

每条提交意图先保存，回执不明确时暂停核对。音乐完成后继续下一条，整批生成后再统一下载。
通过作品编号、精确任务标记、播放控件和时长识别结果；第1首与第10首的标记分别匹配。
下载自动打开指定音乐卡片的右键菜单并选择下载，保留实际音频格式。
默认目录：浏览器默认下载目录 / 即梦音乐 / 主题 / 批次 / 序号_曲名_版本.原格式。
修改下载子目录可调整归档位置；下载根目录由浏览器下载设置决定。
运行时保持浏览器与原对话打开，暂停同页手动创作和其他下载。
“继续检查”只检查已有结果；“确认未创建，重新提交”会再次创建；“重试 / 开始下载”只处理下载。
若旧作品因虚拟滚动暂未加载，回到原对话并滚动到该作品，再重试下载。

运行与隐私

普通使用无需 Python、Node.js或额外驱动。双击 extension/studio.html 可离线预览和生成提示词；控制即梦需要安装扩展。
扩展权限保持为即梦域页面访问、storage、alarms、downloads。不读取或导出账户密码、Cookie或验证码。
提示词由本地类型库和编曲规则生成；音乐与歌词由即梦生成。
源码全部附带，无远程脚本依赖。
