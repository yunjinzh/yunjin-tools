# 数字孪生应用技术员 · 职业能力门户

依据《数字孪生应用技术员国家职业标准（2024年版）》组织的交互门户。职业编码：4-04-05-10。

## 使用

直接打开 `dist/index.html`，或将 `dist/` 作为静态网站目录部署。所有界面、课程、自测、三维模型与实验功能均使用本地资源；外部官方资料链接需联网访问。

页面底部可下载本地版压缩包，解压后双击 `index.html`。Chrome、Edge 等现代浏览器可使用；WebGL 不可用时自动使用 Canvas 软件三维投影。

## 功能

- 5个职业等级、申报条件对照、理论和技能权重切换。
- 7个职业功能领域、46项标准工作内容、条文摘要与练习建议。
- 智能制造、孪生园区、智慧水务3个交互三维实验场景。
- 运行负载、模拟温度、阈值告警、断链和恢复、运行暂停、CSV记录导出。
- 4个飞渡官方产业案例，8个官方学习资源入口，中英术语查询。
- 7个学习单元、10道自编练习、逐题解析、学习建议。
- 本机阅读、练习、收藏、自测和计划记录，JSON导出。
- 按目标等级、每周标准学时生成学习计划。
- 全站搜索、键盘操作、移动布局、减少动态效果偏好适配。

## 内容维护

- `dist/data.js`：标准结构化内容、案例、资源、学习单元、自测与术语。
- `dist/app.js`：门户交互、模拟规则和本机学习记录。
- `dist/styles.css`：布局与视觉样式。
- `src/scene.js`：三维模型、WebGL渲染与软件渲染。
- `vendor/three.module.js`：固定版本 Three.js r170，保留原许可声明。
- `scripts/bundle_scene.py`：构建经典脚本，使本地双击页面能够运行模型。
- `scripts/package_offline.py`：生成页面底部的本地版压缩包。

修改场景后运行 `python scripts/bundle_scene.py`；修改网站后运行 `python scripts/package_offline.py`。原始标准保存在 `dist/assets/standard-2024.pdf`。

## 依据与边界

国家标准制定主体：中华人民共和国人力资源和社会保障部、中华人民共和国工业和信息化部。公布日期：2024年1月31日，人社厅发〔2024〕12号。

企业资料与案例配图来源：北京飞渡科技股份有限公司的 https://www.freedo3d.com/ 与 https://www.freedoonline.com/ ，核验日期2026年10月26日。配图版权归原权利人，原始素材地址见 `dist/assets/asset-sources.json`。

三维场景、模拟数据、自测题与学习计划为本站教学设计。自测结果不等同于职业技能评价；计划模块学时由标准培训参考时长和技能权重计算。学习记录保存在当前浏览器，不自动跨设备同步。
