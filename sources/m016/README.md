# 推文研究档案 1.1

在线工具：https://x-research-archive-yunjin.yunjinzh.chatgpt.site

选择需要研究的推文，统一生成一份 Word 文档和一个交互式 HTML 页面。图片与 MP4 视频集中保存，通过推文编号与正文关联。本版不为每条推文分别生成文件夹或文档。

## 首次使用与更新

1. 解压采集助手安装包，得到 extension 文件夹。
2. Chrome 打开 chrome://extensions，或 Edge 打开 edge://extensions。开启开发者模式，加载 extension 文件夹。
3. 已安装 1.0 版时，将新版文件放到原扩展目录，在扩展管理页点击重新加载。然后刷新 X 页面和在线工作台。
4. 在同一个浏览器登录自己的 X 账号，打开工作台，点击连接 X，选择收藏、点赞与每个页面的浏览上限。
5. 可同时选择今天、近 7 天、近 30 天或自定义日期，并指定按点赞收藏时间、发文时间或采集时间筛选。
6. 采集结束后筛选、勾选所需资料，添加研究笔记，选择电脑保存目录并归档。不勾选时，归档当前筛选结果。
7. 打开 index.html 离线阅读，或打开同一目录中的推文研究资料汇编.docx。

## 统一归档结构

```text
X研究档案/
  推文研究资料汇编.docx
  index.html
  index.csv
  manifest.json
  下载记录.json
  media-cache.json
  media/images/
  media/videos/
```

Word 与 HTML 只收录本次选择。再次在同一归档目录生成汇编时，更新这两个统一文件；已经下载的媒体保留在集中媒体目录，供后续重复归档复用。Markdown 汇编为可选附加导出，默认关闭。旧版已有的归档文件不自动删除。

## 时间段的依据

发文时间、采集时间和点赞收藏时间独立保存。日期范围采用北京时间，包含所选结束日期的全天。先按来源与时间筛选，再选择所需内容归档。浏览上限限制本次页面读取量，未取得的历史记录不计入已完成采集。

2026 年 10 月核查的 X 官方 Get Users Liked Posts 和 Get Users Bookmarks 文档未列出历史点赞、收藏发生时间字段。因此本版使用资料明确提供的互动时间，或新版助手在本浏览器中观察到操作成功响应时的记录时间。后一种依据会显示为助手记录时间，不等同于 X 服务器提供的精确事件时间；记录依赖本机时钟。

历史互动时间缺失时，记录单列为时间待核对，不默认归入确定的时间段。可显式选择同时收录时间未知资料，或在工作台中单独查看、核对。推文发文时间和采集时间不会填充到缺失的点赞收藏时间字段。安装助手以前的互动时间无法由新助手补回。

新版助手只观察用户自己进行的点赞、收藏操作及对应成功响应；不会替用户执行点赞或收藏。成功响应未返回可识别结果时，不生成互动时间记录。

## 交互式 HTML

HTML 页面可离线搜索正文、作者、标签和笔记；按来源、媒体类型和时间段筛选；切换列表与时间线；展开收起正文；放大图片；播放及下载本地视频；添加研究笔记并导出 JSON 备份。笔记修改保存在当前浏览器，离线修改不会自动重写原 Word 文件。

## 媒体与资料核对

本版下载推文本身的图片、MP4 视频以及作为 MP4 提供的动图。引用推文、回复线程和外链网站需分别作为资料导入。媒体地址缺失、服务器拒绝或网络错误会逐项记录，可重试失败项。

文件夹保存需要 Chrome 或 Edge 提供目录选择和写入权限。请在浏览器新标签页打开工作台后使用目录保存。其他浏览器可下载 ZIP 并解压到目标目录。媒体分段写入，单文件上限 2 GB，ZIP 本次资料包上限 256 MB。

## 备份与验证

推文与笔记保存在当前浏览器，归档文件在所选电脑目录。换浏览器或清除站点数据前，先归档或备份 JSON。账号密码和登录 Cookie 不传给工作台。

程序验证覆盖统一 Word 与 HTML、集中媒体保存与复用、选择范围、时区边界、互动时间缺失处理、扩展成功操作记录、媒体流与交互式阅读功能。真实 X 账号和浏览器联调需在安装助手并登录后验证，X 页面结构变化时需更新采集助手。
