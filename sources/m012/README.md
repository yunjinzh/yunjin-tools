# 合同匹配工作台

浏览器内运行的三表匹配工具。源数据保留在当前浏览器内存中，不调用远程数据接口。

## 使用

打开 `dist/index.html`，依次导入合同编码清单、应收表、应付表，选择工作表与表头行。调整匹配字段、汇总字段和输出列后，点击“匹配并生成”。

默认输出15列，按照应收合同名称汇总。需要按单份应收合同计算时，把汇总字段改成合同编号。程序保留未匹配清单，输出对应日志。

结果可下载为Excel。另支持TXT日志、CSV日志，以及包含结果、日志和配置的ZIP。配置可下载和导入，也会存于当前浏览器localStorage。源表内容不持久保存。

## 异常口径

- 清单重复键：保留第一次并记警告。
- 应收重复键：不自动选取，保留问题记录。
- 空项目编码：不执行空值关联。
- 应付重复编号：全行内容相同才自动去重；内容冲突则跳过冲突记录，所在分组合计和占比留空。
- 金额无效：保留原始记录，受影响计算留空。
- 同名/同组跨应收、项目共享：保留关联，记录警告；每组同一应付仅计算一次，不分摊。
- 不执行模糊匹配，不把未匹配金额填成0。

支持.xlsx，单文件30MB；源表公式读取保存的缓存结果，无缓存记警告。旧版.xls需先另存。

## 源码

`core.js`包含读取、匹配、日志与OpenXML导出，`app.js`为界面交互。`style.css`和`index.template.html`为视图。

构建：`node build.cjs`。构建环境需设置`CODEX_PRIMARY_RUNTIME_NODE_MODULES`指向包含JSZip的依赖目录。生成后的HTML内置JSZip，无运行时网络依赖。

测试：`node test.cjs`（测试样例路径由环境变量`CONTRACT_TEST_INPUT_DIR`指定）。测试不把真实合同写入发布目录。
