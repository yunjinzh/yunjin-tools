## 优先级与状态

- **P0**：关键学习路径无法完成，或发生不可恢复的全局故障。本次未确认正常使用路径中必现的 P0。
- **P1**：丢失用户操作成果、要求重复完成已做练习、关键控件难以到达，或隐藏重要反馈。优先修复并回归。
- **P2**：不阻断本次学习，但影响理解、操作效率、一致性或设备体验。
- **已实现，待回归**：代码已经完成，但尚未完成对应操作或设备验证。
- **浏览器通过 / 部分回归 / 逻辑通过**：分别记录实际操作结果、已覆盖子集、Node 或 stub 结果；三者不能混称为全部通过。
- **待规划 / 待设备验收 / 待用户测试**：分别表示尚未实现、缺少目标设备证据、缺少真实用户证据，不能合并称为“已通过”。

## 剩余 P2 的可执行计划

### P2-A：段落级错题与间隔复习

**目标**：让“温故知新”指向具体需要重读的段落，避免只告诉用户整课需要巩固。该方向的学习效果尚待用户测试。

- 数据保持本地：以 `chapterId:verseIndex` 保存题型、最近答题日期、下次复习日期和连续正确次数。理解题仍可挂在课程 ID 上，不能虚构为特定段落错误。
- 首版使用可解释的固定规则：答错加入“待巩固”；重新答对后间隔按 1、3、7 天递增；再次答错回到 1 天。此规则是拟定工程默认值，不宣称是已证实的最佳记忆方案。
- “今日复习”只列到期项；没有到期项时显示可选择的已学段落。用户可主动提前复习，不能通过过期提示制造惩罚或焦虑。
- 不增加后台行为追踪、云端学习画像、自动通知或跨设备身份系统；保留现有记录导入导出，并定义旧版记录迁移。
- **验收**：用可注入日期测试当日、跨日、逾期、时区变化和重复导入；同一段不重复入队；完成对应复习后按规则更新到期日；只完成其他段落不能误清除该错题。
- **用户测试**：观察学习者是否能从“待巩固”直接理解需要做什么；收集主观负担及次日回忆表现后，再决定是否调整间隔。未测试前仅标“待用户测试”。

### P2-B：逐段朗读高亮与可用声库检查

**目标**：让用户明确知道正在读哪一段、能否播放、如何停止。此项属于学习辅助，不扩展为语音识别或发音评分。

- 在用户主动点击后读取系统声库；处理 `voiceschanged` 的延迟返回。显示检测中、有中文声音、无可用中文声音和播放失败四类状态。
- 按原文段落排入语音队列，用段落开始/结束事件更新高亮；不把语音合成边界事件当作可靠的逐字时间轴。
- 课程切换、查看其他页面、隐藏页面或停止朗读后，取消本次队列并清除高亮；使用会话标识阻止旧回调改动新课程。
- 播放启动期间防重复点击；若启动超时，停止本次队列并给出就地提示。超时时间需在目标设备检查后确定，不能让按钮无限显示播放中。
- **验收**：有/无中文声音、声库延迟加载、连续点击、切课、手机后台再返回、系统拒绝播放均可恢复；高亮不得停留在已离开的课程；拼音与文字阅读始终可用。
- **用户测试**：确认儿童或陪学者是否能分辨“待播放”和“正在播放”，以及高亮是否帮助跟读。尚未取得此类观察数据。

### P2-C：真实设备的 WebGL 视觉与性能验收

**性质**：这是现有 3D 体验的验收缺口，不是已经通过的测试结果。几何初始化、Raycaster 或 renderer stub 检查不能证明 GPU Shader 编译、实际光影、真实帧率和移动端稳定性。

| 设备组 | 至少覆盖 | 操作脚本 | 需要留存的证据 |
| --- | --- | --- | --- |
| iOS | 一台实际 iPhone 的 Safari；需要时补同机 Chrome | 首次进入、旋转/缩放、六处地标、昼夜切换、课内学习、后台切换、再次恢复。 | 系统与浏览器版本、屏幕尺寸、场景截图/短录屏、图形错误、恢复结果。 |
| Android | 一台中端和一台较低性能 Android 设备的 Chrome | 连续环游两分钟、快速选课、开合模态、减少动态、后台恢复。 | 设备型号、渲染比例、帧时间统计、长任务、上下文丢失和恢复记录。 |

- 拟定验收目标：六处地标可识别可点，原文界面不被场景遮挡；无持续闪烁、黑屏、材质丢失和无法恢复的上下文错误；移动中端设备连续环游的中位帧率目标不低于 30 fps。此为拟定门槛，未测得结果不能填“达标”。
- 同时记录第 95 百分位帧时间，避免只报告平均帧率掩盖卡顿；记录测试时的分辨率、设备像素比和质量档位，保证结果可复核。
- 学习模态打开、页面隐藏与减少动态状态，应验证场景渲染暂停或明显减少；恢复后相机、题签和按钮状态一致。
- 若设备未达标，先按证据调整像素比、阴影、粒子或按需渲染，再对相同脚本复测。不得只通过删除学习内容来换取性能。
- 视觉审美与真实学习认知负担分别验收。程序正常运行不代表用户认为场景清楚、有趣或愿意继续学习；后者保持“待用户测试”。

## 判定边界

当前确认的是源码改动、上述实际浏览器操作、Node 状态检查及场景 stub 检查。文件选择器自动测试超时与 WebGL 不可用分别构成导入 UI、真实 GPU 验收缺口。本文件不声称进行了儿童样本研究、完成率提升实验、长期记忆实验、完整读屏验收或真实手机 GPU 测试；没有取得结果的项目仍明确保留待验收状态。
