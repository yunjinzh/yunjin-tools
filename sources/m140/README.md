# 三字经 · 云山书院

原生 HTML / CSS / ES Modules + Three.js r170。静态部署目录为 `dist`。

## 内容

- 采用古文岛所载叙史至民初的通行增补本，120 组、480 个三字短句、1440 字，分为 40 课与六境。
- 原文底本：https://m.gushiwen.cn/guwen/bookv_afd03ca45cec.aspx
- 拼音、释义、今读提示与题目见 `dist/content.js`。保留古籍原文并区分传统观念、传说及现代科学。
- 学习流程：逐段读一读 → 全课逐段补一句 → 拼一拼 → 想一想 → 完课休息或继续。允许全文自由选课。

## 功能

程序化水上书院、六处点击地标、OrbitControls、昼夜、巡视、水波 Shader、灯光、阴影、粒子、悬浮书页；收藏、搜索、学习进度、错题巩固与 JSON 记录导入导出。

“动手看看”提供三个与原文关联的知识活动：点选日月星，观察月亮反射阳光；切换四季，观察同一棵北半球温带银杏；排列夏商周，并用年份滑块比较宋、辽、金的同时存在。物件有文字按钮、解释、听读和理解题；二维图解保留等价学习操作，减少动态设置也可使用。

40 课、120 段均可生成单页活动卡，可单独开关拼音与儿童解释，通过浏览器打印或存为 PDF。活动卡不要求姓名、照片或其他个人信息。

听读可选择设备提供的普通话声音并试听；原选声音不可用时自动回退到可用普通话声音。没有合适声库时给出反馈，保留原文、拼音与陪学路径，不以其他语言声音代读。实际发音及离线声音可用性取决于设备，仍需真机核对。

学习记录存于当前浏览器 localStorage，不跨设备自动同步。不可用时提示导出备份。WebGL 不可用时自动进入二维学习模式，保留完整课程和练习。

## 本地与离线

正常开发请使用任一静态服务器提供 `dist`。`node build-offline.mjs` 生成脚本、字体、样式均内嵌的单 HTML；输出路径可通过脚本参数指定。构建使用 Node 内置 vm.Script 校验捆绑脚本。打包 HTML 可在支持 WebGL2 的现代浏览器双击打开；file 协议的持久化行为由浏览器决定。

## 儿童学习版

在完整原文之上增加 40 课目标、120 段儿童白话、就地难词解释、亲子讨论和生活活动。默认轻松学、大字和拼音；练习可切换两选项与四选项。读一小段后再前进，帮助不扣除完成记录。已独立答对后的听读和查原文不追溯降级。

复习按段落及理解题记录，每轮最多 3 项；新学内容隔日再见，到期独立答对后间隔到 3、7 天。同日或提前练习不冒充间隔复习。间隔是透明的起步规则，不代表科学最优参数。所有学习数据仍保存在本机，不上传录音。

运行 `node --test tests/*.test.mjs`：当前 8 个测试文件全部通过，内含 77 项用例（学习状态 15、复习 15、朗读 11、声音选择 6、知识模型 11、知识场景 9、场景生命周期 5、活动卡 5）。语音与渲染器相关测试使用模拟环境，不代表真实设备音画验收；实际验证范围和后续优先级见 `CHILD-LEARNING-PLAN.md`。

本轮单文件版已通过经典脚本解析、字体内嵌和无外部资源标签检查，并通过 HTTP 打开实际单文件核对知识切换与答题。受当前浏览器环境限制，未把本机 file:// 双击、实际断网、真实 GPU 光影及系统中文发音列为已通过。
