## 启动

线上版本直接打开站点链接使用。操作指南中的「下载离线源码包」会打开独立下载页，生成一个完整 ZIP；即使该浏览器无法初始化 WebGL，仍可从 `download.html` 下载。

离线源码包已包含 Three.js、G1 模型、14 类 NVIDIA SimReady 模型、照片材质和 HDR 环境光，不依赖在线 CDN，也不需要构建：

1. 解压整个压缩包，保留目录结构。
2. 安装 Python 3 后，在 Windows 双击 `启动训练系统.bat`；或在其他系统运行 `python3 start_server.py`。
3. 浏览器打开 `http://127.0.0.1:8765/`。
4. 推荐使用支持 WebGL 2 并启用硬件加速的现代桌面浏览器。ES Modules 需要 HTTP 服务，不建议直接双击 `dist/index.html`。
5. 也可将 `dist` 的全部文件部署到静态网站目录，例如 IIS；配置 `.js` / `.mjs` 为 `application/javascript`，`.json` 为 `application/json`，`.glb` 为 `model/gltf-binary`，`.bin` / `.hdr` 为 `application/octet-stream`。

Python 服务仅绑定当前电脑的回环地址。关闭服务窗口即可停止。离线基础功能包括三维场景、任务执行、遥操作、回放与导出；语音输入是否可用取决于浏览器及其识别服务。

## 快速操作

- 桌面选择左侧场景、右侧任务，再点击「开始训练」；小屏使用底部「场景设置」「任务控制」切换。
- F：开启/退出专注模式；Esc：收起小屏面板或退出专注。输入框和弹窗内不会触发 F 快捷键。
- 左键拖动旋转相机，右键拖动平移，滚轮缩放。
- 数字键 1–5：自由、跟随、第一视角、俯视、近景。
- 空格：开始/暂停；R：重置；WASD/方向键：遥操作移动；E：抓取/放下。
- 「单步执行」运行一个完整动作后暂停，不是单帧物理步进。
- 在「机器人」面板开启遥操作；开始自由操作前请先重置未完成的自动任务。
- 点击货物、杯子或餐盘可以查看对象属性。仓库物体还可直接编排搬运。
- 在「环境」面板添加障碍，然后开始任务观察绕行；目标被完全阻挡时会中止并显示原因。
- 训练完成后点击运行控制条中的成绩图标，或在「训练记录」中复盘。

快捷指令示例：`搬运易碎品`、`入库上架`、`制作拿铁送到2号桌`、`来杯美式`、`给3号桌上菜`、`回收1号桌餐盘`、`暂停`、`继续`、`俯视`。

## 评分规则

基础分 = 已完成动作 / 全部动作 × 100，四舍五入。

安全扣分 = 碰撞拦截次数 × 10 + 路径阻塞次数 × 3，最多扣 40 分。

用时扣分 = 超出场景时间预算后每满 5 秒扣 1 分，最多扣 20 分。原型预算：仓库 140 秒、咖啡 90 秒、餐馆 130 秒。

总分 = max(0, 基础分 − 安全扣分 − 用时扣分)。全部动作完成且总分不低于 80 分为达标。评分阈值是此原型的教学设计值，不代表行业标准或真实机器人认证结果。两个训练模式使用相同规则，考核模式隐藏动作说明。

## 技术范围

Three.js 0.180.0 + 原生 JavaScript ES Modules + CSS，无服务端依赖。

- G1 模型按官方 URDF 与原始网格尺寸组装，站立网格高度约 1.32 m，29 个可动关节使用公布的角度限位。场景与物体尺寸、质量为原型设置值。
- 机器人采用 CCD 逆运动学手臂动作和程序化步态，货物随动与咖啡加工采用状态模拟。视觉效果不代表真实硬件的抓取能力、负载能力或运动稳定性。
- 避障针对轴对齐平面障碍边界和底座位置，不含机器人全身动力学、接触力、关节力矩或真实抓取稳定性计算。
- 此版本未接入真实机器人、ROS 2、强化学习训练、大模型或真实传感器。可用于需求沟通、教学演示、任务流程验证，不能据此宣称具备真机控制或训练出的智能策略。
- 语音需要浏览器支持及用户麦克风权限；文字指令可直接使用。应用不包含远程大模型接口或 API 密钥。
- 浏览器记录彼此独立，不提供教师与学生多账号、云端班级管理或跨设备同步。
- 配置导出保存场景设置、任务序列、视图开关、画质与光照设置、自定义障碍。已完成训练的轨迹与运行日志通过「导出完整记录」另存。

## 2.1 取放杯动作修正（2026-10-23）

修正杯子在接触前直接飞向持物点的问题。咖啡杯现在采用独立的接触约束动作控制器，自动任务与遥操作 E 键共用。

1. 机器人按 A* 路径走到台边可达站位，调整朝向。
2. 右手从当前位置连续抬起，对准并靠近杯柄；此时杯子留在台面。
3. 使用 G1 实际关节层级的手部接触坐标测距，距离不超过 0.006 m 才建立持物关系。绑定保留杯子原世界位姿。
4. 咖啡杯绑定实际右手坐标系，随手垂直抬离台面 0.065 m，再收臂。搬运中保持手杯相对位姿与杯口朝上。
5. 放杯时先伸到桌面上方，缓慢下放；杯底位置误差不超过 0.006 m、姿态误差小于 0.025 rad 才松手，随后收回手臂。
6. 操作点不可达或手臂未到位时中止操作；取杯失败时杯子保持台面位置，放杯失败时继续持杯。
7. 暂停和急停冻结动作；新增回放记录保存关节角与手杯绑定。之前保存的旧轨迹仍反映旧版动作。

取杯点调整到吧台边缘，配送点位于圆桌可达的前缘。路径规划保留原有碰撞余量，并在连接精确停靠点时检查连接线段，避免网格取整把站位误判到桌内。

新增 8 项专项检查覆盖：接触前静止、绑定瞬间零跳变、持续刚性随手、杯底落稳松手、取杯时右臂网格与台面间隙、遥操作、暂停/急停/回放、不可达与阻挡、持杯重置，以及精确停靠点路径。检查使用实际 G1 网格和关节，不替换运动学模型；GPU 提交仍使用测试替身。

这是基于几何接触与逆运动学的取放杯演示；固定手部网格没有独立手指关节动画，未计算接触力、摩擦、负载稳定性或真机控制。货箱与餐盘继续使用原有示范流程。

### 资源准备脚本（仅开发时使用）

运行应用和离线包不需要这些依赖。重新准备模型时，安装 Python 的 `usd-core`、`numpy`、`Pillow`，并在单独的工具目录安装 `@gltf-transform/core`、`@gltf-transform/extensions`、`@gltf-transform/functions` 与 `meshoptimizer`。本次使用版本为 usd-core 26.11、NumPy 2.3.5、Pillow 12.3.0、glTF Transform 4.5.1 和 meshoptimizer 1.3.0。

```sh
python3 scripts/prepare_simready_assets.py --cache /path/to/simready-cache
python3 scripts/convert_simready_assets.py --cache /path/to/simready-cache
SIMREADY_TOOLS_ROOT=/path/to/tools node scripts/optimize_simready_assets.mjs
```

`SIMREADY_TOOLS_ROOT` 指向含上述 npm 包的工具项目目录；也可在本项目安装这些开发包后省略该环境变量。转换应先于优化；不要对已经优化的 GLB 反复运行减面。全部 GLB 已内嵌贴图后，转换阶段的 `dist/assets/simready/textures` 中间目录可以删除。来源固定为 `524747d9b5e1f21b5b18b56041788c01d745f1a1`，每个模型的 JSON 记录实际使用的源文件与 SHA-256。

离线发布包由 `python3 scripts/package_offline.py --output /path/to/embodied-studio-source.zip` 生成。静态站点传输分块后在浏览器合成一个 ZIP，用户不需要手工合并；每块记录大小与 SHA-256，HTTPS 环境下载时校验哈希。下载分块不再放入 ZIP 内，避免递归打包。另有 2 项检查验证完整 ZIP 重组与传输截断时的报错；源码 ZIP 中不含传输分块，直接运行测试时会跳过这 2 项，先执行上述打包脚本即可恢复这两项发布检查。
