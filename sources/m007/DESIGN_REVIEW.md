# 具身工场 3.0 设计检查

日期：2026-10-24。目标：围绕三维任务训练，重做版式与交互品质。获奖站点用于参考，不代表本项目获得奖项、评分或认证。

## 参考与观察

- Awwwards：Serve Robotics，Site of the Day，2026-06-11。官方案例 https://www.awwwards.com/sites/serve-robotics 。参考其大面积主视觉、清晰的品牌色和分层导航方向；将其转换为训练工作台的信息优先级，而不是营销落地页。
- The Webby Awards：Bézier，2025 Best Visual Design – Function 获奖。官方案例 https://winners.webbyawards.com/2025/websites-and-mobile-sites/features-design/best-visual-design-function/324140/bzier ，实际访问 https://www.bezier.com/en 。观察到克制的导航、突出主体的大幅视觉与字体节奏。转化为大标题、数值字体、紧凑功能文字三种层级。
- FWA：Interaction Library，2026-10-22 FWA of the Day。官方页面 https://thefwa.com/cases/interaction-library ，实际作品 https://library.jjangik.kr/ 。浏览器核对了获奖日期、作者 Jungik Lee、空间书架/列表切换及 Escape 返回的可访问结构。该作品在本验收浏览器中未呈现完整视觉内容，因此不声称完成其动效视觉对比。借鉴的是空间主导和可退出交互的方向。

上述观察是设计判断，并非对不同类型产品作量化评分。

## 八项检查

| 维度 | 本轮改动 | 自查与修正 |
|---|---|---|
| 字体 | 本地中文宋体标题、黑体控件、窄体数值、等宽索引 | 字体子集化、保留许可、重命名；将功能说明与手机控件字号调大 |
| 留白 | 独立标题区、可伸缩三维区、固定节奏的面板间距 | 1280 桌面完整检查；小屏不再挤放三栏；短屏降低视口最低高度 |
| 层级 | 场景标题、珊瑚色主操作、任务序列和实时指标分别成组 | 选中状态、主操作、次要工具分开；专注模式隐藏两侧面板 |
| 色彩 | 银白背景、深墨控制区、合欢红强调 | 降低原有绿调饱和度；正文次级色加深。主操作文字对比度约 4.64:1，强调文字约 5.51:1（纯色静态计算，不代替完整无障碍审计） |
| 动效 | 250–450ms 面板/场景/弹窗过渡，运行点轻脉冲 | 遵从 prefers-reduced-motion；无滚动劫持；不新增机器人行走轨迹 |
| 微交互 | 卡片悬停、页签下划线、按钮按压、键盘焦点、F / Esc | 输入与弹窗不会被 F 抢焦点；面板切换后焦点落在可见区域；播放文字只在状态变化时更新 |
| 响应式 | 桌面三栏；平板与手机底部切换；小屏重排任务编排 | 浏览器检查 1440、1280、834、390、320 CSS 像素宽度。320 的卡片微标签重叠已修正；隐藏区域及被覆盖的三维区使用 inert |
| 原创性 | 中文编辑式排版、编号场景、仪表数值、上传品牌标识 | 保留产品的真实 G1 / SimReady 场景与训练流程，没有套用参考作品的页面或资产 |

## 迭代记录

1. 第一轮：重建版式、字体系统、主配色与工作台分区。
2. 第二轮：根据桌面及手机截图，调大功能文字、降低面板绿调、增加被遮挡区域隔离与焦点恢复。
3. 第三轮：修正 320px 卡片标签重叠、短屏底部切换需要滚动的问题，统一离线下载页。
4. 最后检查：源码语法、56 项自动检查、字体许可和离线 ZIP 完整性。新增 4 项测试验证专注、键盘保护、小屏焦点与断点切换。

## 验证边界

测试浏览器不能创建 WebGL context。HTML/CSS 布局验收使用临时测试入口，仅替换 GPU 提交，保留实际模型加载、场景图和任务逻辑；画布明确标注“GPU NOT RENDERED”。该入口不会发布，也不进入离线包。

因此当前已检查界面布局和交互回归，实际 GPU 渲染、场景缩略图和三维光照仍需在支持 WebGL 2 的环境复核。不能据此判定所有维度达到“无任何可改进之处”；该结论不具有客观、可重复的验收标准。本轮停止点是已修正观察到的界面问题，并明确保留尚未验证的三维视觉项。
