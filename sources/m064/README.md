# MUSE 资源展示平台

会员制图片与 PPT 资源展示平台，包含注册登录、管理员审核、资源搜索排序、瀑布流展示、高清图片预览、PPT 下载、收藏记录及个人中心。

## 默认管理员

- 用户名：`admin`
- 密码：`admin888`

首次部署后请尽快在个人中心修改密码。

## 自动收录资源

将资源放入 `public/resources/`，每次启动或构建时会自动扫描并生成资源清单。

- 图片：`jpg`、`jpeg`、`png`、`webp`、`gif`、`avif`、`svg`
- 文档：`ppt`、`pptx`
- 子文件夹名称会自动作为资源分类
- PPT 封面使用同目录、同文件名的图片，例如 `年度报告.pptx` 与 `年度报告.jpg`

## 本地运行

```bash
npm run dev
```

## 数据说明

按照设计文档要求，账户、审核状态、收藏和下载记录均存储于浏览器 `localStorage`。这适用于独立演示或单机使用，不属于生产级鉴权方案。正式付费平台应将账户、权限、支付状态和资源文件迁移到服务端数据库与对象存储，并由服务端执行权限校验。
