京城夜行 · 北京城市漫游
版本：1.0.0

这是一款浏览器中的北京主题三维城市游戏。交互参考 dzyai.online 的城市漫游玩法，使用自主编写的游戏逻辑、程序化地标、人物、车辆与合成音乐。地图为压缩创作场景，不是测绘地图，也不提供现实出行导航。

启动
双击“启动京城夜行.cmd”。启动器使用本机已安装的 Node.js，或当前电脑 Codex 附带的 Node.js，自动打开浏览器。资源全部包含在 dist 中，运行期间不需要下载地图、模型、字体或音乐。
推荐启用硬件加速的桌面 Chrome / Edge。低性能设备可在“暂停与设置”中选择“流畅”；触屏可启用屏幕按键。移动端建议横屏。
停止本地服务：双击“停止京城夜行.cmd”。仅停止此启动器记录且核实为本项目的服务。
开发启动：node server.mjs
默认地址：http://127.0.0.1:4205
验证逻辑：node tests/core.test.mjs

已实现的玩法
1. 自由步行、冲刺、蹲行、鼠标环视。
2. 汽车上下车、加速、转向、倒车、制动、氮气加速。
3. 什刹海游船驾驶、岸边上下船与接驳任务。
4. 跟随、第一人称与俯视三种镜头。
5. 城市交通、行人、路口与建筑碰撞。
6. 城市地图、地标导航、小地图与地面引导箭头。
7. 夜班交接：前门取件、限时送往国贸。
8. 胡同回声：鼓楼取件、摆脱巡逻再交付。
9. 二环夜跑：九道检查门、计时与个人最好成绩。
10. 雨夜寻声：798 潜入、蹲行、警戒度与撤离奖励。
11. 什海夜渡：登船、收取邮袋、低速返回。
12. 街巷速递：重复接单与配送计数。
13. 十二盘城市磁带的收集与现金奖励。
14. 前门车坊五种涂装、三级动力与氮气升级。
15. 白天、黄昏、夜间以及晴天、雨天、薄雾。
16. 三个原创合成旋律电台与发动机声音。
17. 巡逻追踪、警戒消退与被拦截处罚。
18. 自动存档、JSON 导入导出、画质和操作设置。

北京场景
故宫与天安门、鼓楼与景山、什刹海、南锣鼓巷胡同、前门大栅栏、北海白塔、国贸与中国尊、天坛祈年殿、奥体鸟巢、798 艺术街区、前门车坊。

操作
WASD / 方向键：移动或驾驶
E：交互、取件、交付、收集、上下车船
Shift：冲刺或汽车氮气
Space：车辆制动
Q：步行蹲下
M：城市地图
C：切换镜头
R：切换电台
N：切换时间
X：切换天气
Esc / F2：暂停与设置
鼠标拖动：转动视角；点击场景可锁定鼠标，Esc 释放。

存档与边界
存档保存在当前浏览器、当前网址的 localStorage。在线版与本地版、不同浏览器之间不自动同步，可通过“导出存档”和“导入存档”转移。自动保存现金、已完成故事、磁带、竞速最好成绩、配送次数、车辆升级、配色、位置与设置；进行中的任务重新打开后需要重新接取。船上存档重开后会回到安全位置。导入前会在本地保留上一次存档副本。
游戏为单机网页版本，不含多人联机、真实地图服务或原网站账号体系。场景与任务为北京主题重新设计，并非原站素材的逐像素复制。

源码结构
dist/index.html：界面
dist/style.css：布局、视觉与响应式
dist/game.js：三维渲染、输入、驾驶、任务、音频和存档
dist/core.js：任务数据、导航与存档校验
dist/world.js：程序化北京城与碰撞体
dist/actors.js：合批车辆、人物与游船模型
dist/vendor/three.module.js：Three.js 0.160.1（MIT）
tests/core.test.mjs：存档、导航、碰撞边界与任务配置验证
server.mjs：本地静态服务
.openai/hosting.json：Sites 部署配置
