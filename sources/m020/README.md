# CIM 研习社

面向高校与高职学生的 CIM 基础平台自主学习网站。依据用户提供的《CIM基础平台白皮书v3.0_20221114》及11段操作视频整理，保留资料原文与完整视频。

## 学习与教学功能

- 10个模块、36节微课：目标、概念、讲解、操作步骤、常见问题、随堂检查与笔记。
- 11段操作视频，按需加载60个片段；支持章节定位、续播、倍速、进度跳转、完整视频回顾。
- 12项教学模拟训练：引导、练习、考核；包括可旋转、选取建筑、测距和保存视点的三维校园。
- 120道知识题，随机组卷、答案后台保存、截止自动交卷、后台评分、错题重练、逐题解析。
- 3项综合项目，报告与附件提交，教师依据评分量表批阅。
- 个人时长、课程完成、操作考核、项目成绩与学习档案导出。
- 教师班级、班级码、学习任务、学情导出、成果批阅、课程与题库修订。管理员可分配教师角色。

## 账户和访问

使用托管平台提供的 ChatGPT 登录身份，网站代码不保存密码。新网站保持所有者私密访问。首次访问者在私密状态下初始化为管理员。之后新增账户默认为学生。教师仅可查询自己班级的学生，管理员可管理全站；学生只可读取自己的学习与附件记录。

首次登录后可从左侧进入教师工作台，创建班级、发布学习任务。准备班级试用时，需先在网站的访问权限设置中为目标用户开放访问。班级码仅用于站内分班，不绕过站点的访问控制。

## 教学范围

这是一套学习、考核与教学模拟系统，没有连接原厂 CIM 引擎。模拟界面不等同于真实软件操作认证。实机项目需要学校提供可用平台、素材与权限；尚无实机条件时可提交注明“模拟成果”的方案。白皮书对应2022版本；不以白皮书年份推定视频的软件版本。实际部署的菜单、接口、支持格式需以该部署文档为准。没有虚构完整 SDK 文档或有效业务接口。

视频章节时间来自画面核对，属于近似定位。全文讲解与操作步骤提供文字辅助，不声称逐字视频字幕。白皮书页码采用 PDF 的实际物理页。

## 数据与计时

D1 保存账户、进度、笔记、时长事件、考试、实训、班级、任务与项目评价。R2 保存项目附件。离线心跳暂存于当前设备，恢复后补报；草稿报告按用户和项目分别保存在当前浏览器。完整学习记录保存在后台。

计时按可见页面中的活动采样；阅读、练习、考试连续两分钟无输入或滚动暂停计时，视频按真实播放状态记录。重复的事件ID和重叠时段去重，日期按中国标准时间汇总。倍速按真实经过时间计时，视频覆盖率按有效播放区间合并。计时是学习活动证据，不是监考或强身份验证。

能力达标要求：36课通过检查点、综合正式考试80分、12项独立操作考核各80分、3项项目经教师评分各80分。综合分按照理论30%、操作40%、项目30%计算，单项条件仍需分别满足。

## 维护

- `data/course.json`：课程基线；教师可在站内修订讲解。
- `data/assessment.json`：题库、训练与项目基线；标准答案只在服务端评分，试题通过受保护接口下发。
- `app/api/[...path]/route.ts`：身份校验、D1、R2与业务接口。
- `components/learning/`：学习端、教师端、视频与三维场景。
- `public/media/manifest.json`：视频片段映射。
- `db/schema.ts`、`drizzle/`：数据库结构与迁移。

开发检查：

```sh
pnpm exec tsc --noEmit
node scripts/check-learning.mjs
```

自动检查覆盖内容与资源完整性、跨日时长合并、后台评分、考试截止、重复交卷、记录保存、角色和班级隔离、附件访问权限。SQLite 与云存储测试替身用于验证业务行为；不是生产环境端到端测试。通过 Sites 的构建和发布流程上线，数据库迁移由托管流程应用。

## 首版验证范围

已完成类型检查、生产构建和关键逻辑自动检查。本执行环境没有可用的受支持浏览器测试工具，因此尚未逐页进行浏览器视觉检查或登录后的生产端到端操作验收。建议首轮体验检查视频播放、三维交互、一次完整考试及项目附件提交，再开放班级试用。
