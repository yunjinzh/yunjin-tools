## 版本依据

初次迁移的 Sites 源码使用当时源仓库的最新提交；后续自动同步选取已完成发布的保存版本对应提交。源提交 SHA 和版本号记录在 `modules.json`。运行产物由已取回源码、已存在的静态导出以及本次 React 静态构建产生；不保证与原站最近一个发布版本字节一致。原来的功能限制保留在各项 `original_status` 字段。

大资源按 SHA-256 存入 `assets/`，原路径映射保存在每个模块的 `migration-assets.json`。构建时将图片、音频及下载包转为当前仓库 Raw 资源链接，模型与关键字体保留在 Pages 目录。脚本与目录可独立重复构建；React 适配产物存于 `web/`。
