Modifications: OpenUSD to static glTF 2.0 conversion; metre units, Y-up axes
and floor-centred origins; geometry simplification (relative error limit
0.001), vertex quantization, meshopt compression, material consolidation,
UV/UDIM atlas conversion, texture resizing and JPEG/PNG encoding. Some large
source maps use the publisher's 512-pixel mip versions; other maps are capped
at 1024 pixels per tile (the rack atlas combines three tiles). Metallic,
roughness, normal and emissive maps are retained when present. Transparent
glass is an alpha approximation. The served steak uses an application shader
that remaps the original raw-meat color to cooked browns. A source cardboard
trim's incorrectly bound ORM-as-normal map is omitted.

Application placement applies scaling to selected props to fit interaction
settings; carton size variants are non-uniformly scaled. The floor-standing
coffee vending appliance retains its published size. The racks receive an
additional application-authored reachable middle shelf. Repeated static
objects use GPU instancing; interactive cargo retains individual geometry.

Source USD physics schemas, sensors and simulation metadata are NOT imported
into the web prototype. This use does not add PhysX, Isaac Sim, MuJoCo, Newton
or validated physical robot training. No NVIDIA affiliation or endorsement
is claimed. Full source URLs and input/output SHA-256 hashes are recorded in
simready/manifest.json and each model's companion JSON.
